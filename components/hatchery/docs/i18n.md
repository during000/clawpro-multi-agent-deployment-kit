# 国际化 (i18n) 方案

## 概述

使用 `golang.org/x/text/message` 包实现中英文国际化，仅覆盖 API 层的用户可见消息（错误提示、业务文案）。

- 支持语言：中文（默认）、英文
- 范围：`writeError`、`jsonOK` 等 API 响应中的用户可见文案
- 不涉及：日志消息（保持中文，面向运维）、`templates/`（已废弃）

## 技术选型

| 包 | 用途 |
|---|---|
| `golang.org/x/text/message` | 国际化消息格式化（替代 `fmt.Sprintf`） |
| `golang.org/x/text/language` | 语言标签解析、匹配 |

项目已间接依赖 `golang.org/x/text v0.34.0`，无需新增依赖。

## 目录结构

```
hatchery/
├── i18n/
│   ├── i18n.go       // Middleware、语言检测、Printer context 注入、T() 函数
│   ├── keys.go       // 消息 Key 常量（值为中文原文）
│   └── en.go         // 英文翻译注册
```

## 核心设计

### 原则：中文做 fallback，只维护英文翻译

`message.Printer` 在 catalog 中找不到翻译时，直接把 key 当 format string 输出。利用这一机制：

- 常量值为中文原文 → 中文场景下 catalog 无匹配 → 直接输出中文（零成本）
- 只需维护 `en.go` 一个翻译文件

### 常量定义 (`i18n/keys.go`)

用 `Key` struct 消除字符串拼写不一致的风险。Key 的 `string` 字段就是中文原文：

```go
package i18n

type Key struct {
    string
}

// 认证相关
var (
    MsgInvalidCaptcha     = Key{string: "验证码错误"}
    MsgInvalidCredentials = Key{string: "用户名或密码错误"}
    MsgAccountBanned      = Key{string: "账户已被封禁"}
    MsgIncompleteForm     = Key{string: "请填写完整"}
    MsgUserNotFound       = Key{string: "用户 %s 不存在"}
    MsgOldPasswordWrong   = Key{string: "原密码错误"}
)
```

### 英文翻译注册 (`i18n/en.go`)

```go
package i18n

import (
    "golang.org/x/text/language"
    "golang.org/x/text/message"
)

func init() {
    message.SetString(language.English, MsgInvalidCaptcha.string, "Invalid captcha")
    message.SetString(language.English, MsgInvalidCredentials.string, "Invalid username or password")
    message.SetString(language.English, MsgAccountBanned.string, "Account has been banned")
    message.SetString(language.English, MsgUserNotFound.string, "User %s not found")
    // ...
}
```

### 核心逻辑 (`i18n/i18n.go`)

```go
package i18n

import (
    "context"
    "net/http"

    "golang.org/x/text/language"
    "golang.org/x/text/message"
)

// 支持的语言，index 0 为默认语言
var matcher = language.NewMatcher([]language.Tag{
    language.Chinese, // 默认
    language.English,
})

type ctxKey struct{}

// Middleware 解析请求语言偏好，将 *message.Printer 注入 context。
func Middleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        lang := detectLang(r)
        printer := message.NewPrinter(lang)
        ctx := context.WithValue(r.Context(), ctxKey{}, printer)
        next.ServeHTTP(w, r.WithContext(ctx))
    })
}

// detectLang 按优先级检测语言：
//  1. URL 查询参数 ?lang=en
//  2. Accept-Language 请求头
func detectLang(r *http.Request) language.Tag {
    if q := r.URL.Query().Get("lang"); q != "" {
        tag, _ := language.Parse(q)
        matched, _, _ := matcher.Match(tag)
        return matched
    }
    accept := r.Header.Get("Accept-Language")
    tag, _ := language.MatchStrings(matcher, accept)
    return tag
}

// Printer 从 context 中获取当前请求的 Printer。
func Printer(ctx context.Context) *message.Printer {
    if p, ok := ctx.Value(ctxKey{}).(*message.Printer); ok {
        return p
    }
    return message.NewPrinter(language.Chinese)
}

// T 翻译并格式化消息，用法与 fmt.Sprintf 一致。
func T(ctx context.Context, key Key, args ...interface{}) string {
    return Printer(ctx).Sprintf(key.string, args...)
}
```

## 语言检测规则

| 优先级 | 来源 | 示例 |
|---|---|---|
| 1 | URL 参数 `?lang=` | `GET /api/instances?lang=en` |
| 2 | HTTP 头 `Accept-Language` | `Accept-Language: en-US,en;q=0.9,zh-CN;q=0.8` |
| fallback | 默认中文 | 无匹配信息时输出中文 |

## 使用方式

### 基本用法

```go
// Before
writeError(w, r, http.StatusBadRequest, errors.New("验证码错误"))

// After
writeError(w, r, http.StatusBadRequest, errors.New(i18n.T(r.Context(), i18n.MsgInvalidCaptcha)))
```

### 带参数的消息

```go
// Before
writeError(w, r, http.StatusNotFound, fmt.Errorf("用户 %s 不存在", username))

// After
writeError(w, r, http.StatusNotFound, errors.New(i18n.T(r.Context(), i18n.MsgUserNotFound, username)))
```

### 参数顺序重排（中英文语序不同时）

利用 Go 标准的 `%[n]` 索引语法：

```go
// keys.go
var MsgMoveItem = Key{string: "将 %s 从 %s 移动到 %s"}

// en.go — 英文需要重排参数顺序
message.SetString(language.English, MsgMoveItem.string, "%[3]s now contains %[1]s (moved from %[2]s)")
```

## 运行时行为

| 请求语言 | `i18n.T(ctx, i18n.MsgInvalidCaptcha)` | 原理 |
|---|---|---|
| 中文 / 未指定 | `"验证码错误"` | catalog 无中文条目 → key 原样输出 |
| 英文 | `"Invalid captcha"` | 命中 en.go 注册的翻译 |

| 请求语言 | `i18n.T(ctx, i18n.MsgUserNotFound, "admin")` | 结果 |
|---|---|---|
| 中文 / 未指定 | `"用户 admin 不存在"` | fallback → Sprintf(key, args) |
| 英文 | `"User admin not found"` | 翻译后 Sprintf |

## 接入步骤

### 1. 注册 Middleware

在 `main.go` 中，将 `i18n.Middleware` 加入全局中间件链（在路由注册之前）：

```go
import "hatchery/i18n"

func main() {
    mux := http.NewServeMux()
    // ... 路由注册 ...
    handler := i18n.Middleware(mux)
    // ... 其他中间件 ...
    server := &http.Server{Handler: handler}
}
```

### 2. 全量改造 controller

一次性替换所有 controller 中的用户可见中文字符串，包括：

- `auth.go` — 登录/密码/Token 相关错误
- `llm_proxy.go`, `llm_quota.go` — LLM 代理 API
- `openclaw_*.go` — 用户侧业务操作
- `admin_*.go` — 管理后台
- 其他所有 handler 中 `writeError`/`errors.New`/`fmt.Errorf` 返回给用户的中文

### 3. 新增消息的工作流

1. 在 `i18n/keys.go` 添加 Key（值为中文原文）：`var MsgXxx = Key{string: "中文原文"}`
2. 在 `i18n/en.go` 添加 `message.SetString(language.English, MsgXxx.string, "English text")`
3. 代码中使用 `i18n.T(ctx, i18n.MsgXxx, args...)`

## 注意事项

- **不要在 context 不可用的地方调用 `T()`** — 如 `init()`、全局变量初始化。这些场景的错误信息通常是面向开发者的，保持硬编码即可。
- **`fmt.Errorf` 包装的 error** — 如果是给用户看的消息，换成 `errors.New(i18n.T(ctx, ...))`；如果是内部 wrap（`%w`），保持原样不需要国际化。
- **日志不做国际化** — `slog.Warn("更新失败", ...)` 保持中文，面向运维。
- **带 `%w` 的 error** — 不能用 `i18n.T` 直接替换 `fmt.Errorf("...%w", err)`。拆分为：外层翻译给用户看的消息 + 内部 wrap 保持原样。

## 测试

```go
func TestT_Chinese(t *testing.T) {
    ctx := context.Background() // 无 Printer → fallback 中文
    got := i18n.T(ctx, i18n.MsgInvalidCaptcha)
    assert(got == "验证码错误")
}

func TestT_English(t *testing.T) {
    printer := message.NewPrinter(language.English)
    ctx := context.WithValue(context.Background(), ctxKey{}, printer)
    got := i18n.T(ctx, i18n.MsgInvalidCaptcha)
    assert(got == "Invalid captcha")
}

func TestT_WithArgs(t *testing.T) {
    printer := message.NewPrinter(language.English)
    ctx := context.WithValue(context.Background(), ctxKey{}, printer)
    got := i18n.T(ctx, i18n.MsgUserNotFound, "admin")
    assert(got == "User admin not found")
}
```
