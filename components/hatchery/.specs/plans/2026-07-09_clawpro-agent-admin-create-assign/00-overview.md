## 关键决策备忘

> **跨阶段共享的关键上下文**。仅记录影响后续步骤的决策，避免恢复时还要翻阅历史阶段文件。

- TAPD 需求：长 ID `1020422209135676012`，短 ID `135676012`，项目 `20422209`。
- 仅新增后端 CVM Agent 创建能力；普通用户创建接口、前端和本地 Agent 预创建不在范围内。
- 用户端与管理员端共用 `createInstance(..., createInstanceOptions)` 主流程；管理员入口只增加目标用户、目标分组和预设解析。
- 所有支持模型配置的运行时可指定一个初始模型；仅 OpenClaw 兼容运行时支持 fallbacks，OpenClaw 3.28.x 不支持 fallback。
- 模型、手动通道和追加技能等待 Agent ready 后异步下发，并分别复用用户端 `add-model`、`set-channel`、`add-skill` 的核心实现。
- 创建期通道凭据和追加技能意图不持久化、不重试、不恢复；source 省略时技能来源默认 `public`。
- 管理员创建请求体和 TAT 参数值不得进入结构化日志。

## 风险速览

| # | 风险 | 严重度 | 缓解 |
|---|------|-------|------|
| 1 | 管理员可能绕过目标用户、分组、配额或资源可见性边界 | 高 | 在申请 CVM 前完成用户、分组、配额、能力和可见性校验 |
| 2 | 创建期通道凭据进入日志、审计或响应 | 高 | 跳过请求体日志，脱敏 TAT 参数和脚本错误，不回显 presets |
| 3 | 非持久化异步预设在进程退出或下发失败后丢失 | 中 | API 文档明确无重试、无恢复；管理员可在 Agent ready 后通过现有接口重配 |
