## 执行命令

```bash
# 目标用例
go test ./model ./controller -run '<本任务测试函数正则>'

# 本任务变更路径：竞态检测 + 覆盖率
go test ./model ./controller -race -run '<本任务测试函数正则>' \
  -coverprofile=coverage-skill-operations.out

# 静态检查
go vet . ./controller ./model

# 全量尝试
go test ./... -v -race -coverprofile=coverage.out
```

目标用例、目标竞态检测和静态检查均通过。全量命令未通过：仓库现有全量测试存在多处全局测试 DB/Hook 数据竞争及与本任务无关的失败，主要集中于既有 controller/task 测试；本任务新增测试未出现在失败列表中。

Commit 后扩展验证：`go test ./controller -run 'Test(EnrichDistributedSkillVersions|HandleUserUpdateSkill|HandleUserUninstallSkill|HandleUserUpdateAndUninstallSkill|SkillOperationHandlers|SkillTaskExecution)' -count=1 -race` 通过。
`can_uninstall` 扩展验证：三个列表脚本黑盒用例、列表补充及直接卸载目标用例在 `-race` 下通过。
直接卸载收敛验证：无 Admin 下发状态的路径不再注入或调用实时列表 seam；三运行时每次请求恰好执行一次卸载脚本，重复请求仍返回 true。

增量覆盖率脚本在未提交工作区执行时按 `origin/master...HEAD` 比较，未识别未提交 Go 文件，不能作为本阶段有效门禁结果；Commit 后需在 CI 重新执行。
