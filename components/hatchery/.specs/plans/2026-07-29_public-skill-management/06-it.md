## 失败用例定位

1. 首轮和首次重试在 `setup_instance()` 的 Gateway UI 前置检查超时。探针确认 RuleSet 已同步、实例绑定同一 SG、无 drift，但 Gateway 访问预检仍返回未放通。技能列表、更新、卸载实际走 TAT，不依赖 Gateway UI；最终用例改为只等待三类实例进入 `running` 并等待运行时稳定，避免把独立的 Gateway 安全组问题混入本任务。
2. 首次进入技能断言时，Enterprise 运行时 `name` 返回 slug。接口契约只保证 `name` 来自 Agent 实际列表，不保证等于 Admin 元数据；修正为 Enterprise 仅校验非空名称，并由稳定 Public fixture 验证 `name != slug`。
3. 最终运行无失败用例；所有临时诊断代码和临时仓库凭证均已清理。
