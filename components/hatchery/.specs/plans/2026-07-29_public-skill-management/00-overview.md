## 关键决策备忘

> **跨阶段共享的关键上下文**。仅记录影响后续步骤的决策，避免恢复时还要翻阅历史阶段文件。

- 仅实现后端；范围限于 CVM OpenClaw、Hermes、LightClaw ACE。版本展示与更新仅针对 Admin 下发的 Public/Enterprise 技能；卸载扩展到实时列表中可实际移除的其他技能。
- 扩展 `GET /openclaw/skills`：所有实时技能返回稳定 `slug` 和 `can_uninstall`；OpenClaw/ACE 命中用户技能目录时可卸载，仅 CLI 可见或 builtin 的内建技能不可卸载，Hermes 目录技能可卸载；仅命中有效 Admin 下发记录的实际技能增加版本与更新字段。
- 新增表单接口 `POST /openclaw/update-skill`、`POST /openclaw/uninstall-skill`，均以 `id`、`slug` 定位用户本人单 CVM；更新仅支持 Admin 下发技能，卸载支持可移除的运行时技能。
- Admin 下发技能操作复用现有来源/版本解析、制品准备、Agent 脚本、技能级锁和 task/record；其他技能卸载只复用物理 executor，不补造 Admin 记录。
- 当前安装状态按同实例同 slug、跨 Public/Enterprise 的成功操作序列还原；pending/failed 不改变当前版本。
- Public 最新版本按 slug 缓存 5 分钟，列表可用过期缓存降级，更新不可使用过期缓存；Enterprise 更新重新校验用户可见性。
- 路由继续沿用仓库主流的 path-only 注册 + Handler method guard；不因孤立文字规则引入第二套路由风格。Enterprise 用户操作按 Admin 准备后的目标/最新 SkillID 加锁。
- 更新接口响应仅保留更新前 `old_version` 和完成后 `version`；`latest_version` 只在技能列表返回，避免同步响应重复字段。
- `can_uninstall` 由列表提供给前端；无 Admin 下发记录时不再执行远程列表复核，获取 runtime+slug 锁后只运行一次幂等卸载脚本，脚本成功统一返回 true。

## 风险速览

| # | 风险 | 严重度 | 缓解 |
|---|------|-------|------|
| 1 | 分发记录最新行可能是 pending/failed 目标版本，误判当前版本 | 高 | 按成功 distribute/uninstall 事件序列还原并覆盖交错状态测试 |
| 2 | Public 仓库故障或同 slug 并发查询放大延迟 | 中 | 5 分钟缓存、过期降级与同 slug 请求合并 |
| 3 | Agent 显示名 `name` 与 Admin 分发 `slug` 可能不同 | 高 | 运行时列表内部保留安装目录 slug，管理字段与写接口统一使用 slug |
| 4 | Admin 执行器为批量异步，用户接口要求单实例同步 | 高 | 复用底层准备/脚本/记录能力，不直接调用 Admin Handler 或复制链路 |
