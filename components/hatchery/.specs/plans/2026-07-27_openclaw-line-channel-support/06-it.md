## 前置检查

> 开始前逐项确认，缺一项即无法运行集成测试。

- [ ] Docker 可用：`docker info` 正常
- [ ] 镜像仓库已登录：`docker login` 完成
      （凭证获取：https://console.cloud.tencent.com/tcr/repository/tcr/tcr-4531z75r/cvm-openclaw/hatchery/1/tagList →「仓库信息」tab）
- [ ] Kubeconfig 可用：`kubectl --kubeconfig <path> cluster-info` 正常
      （下载：https://console.cloud.tencent.com/tke2/cluster/sub/list/basic/info/apiserver?rid=1&clusterId=cls-m29jw7bu，放到 `~/.kube/config` 或设 `KUBECONFIG`）
- [ ] AK/SK：已通过 `--ak`/`--sk` 传入
      （必须用 3205597606 账号，其他账号未加白名单）

## 新增测试文件

| 文件 | 说明 |
|------|------|
| `test/scripts/channel/test_line_channel_hermes.py` | TC-H4.8 Hermes LINE 通道配置 + 查询确认 + 删除完整流程 |

### 环境变量

| 变量 | 必填 | 说明 |
|------|------|------|
| `LINE_CHANNEL_ACCESS_TOKEN` | ✅（海外站点） | LINE Messaging API Channel Access Token |
| `LINE_CHANNEL_SECRET` | ✅（海外站点） | LINE Messaging API Channel Secret |

### helper 变更

| 文件 | 变更 |
|------|------|
| `helpers/config.py` | 新增 `LINE_CHANNEL_ACCESS_TOKEN` / `LINE_CHANNEL_SECRET` 惰性环境变量 |
| `helpers/channel.py` | `SITE_SCOPED_CHANNELS` 新增 `"line": {"overseas"}` |
| `helpers/hermes.py` | `HERMES_WHITELIST_CHANNELS` 新增 `"line"` |

## 测试用例设计

| # | 用例 | 方法 | 路径 | 预期结果 |
|---|------|------|------|----------|
| 1 | 非海外站点跳过 | `GET /site` | `is_overseas_site()` 返回 False | 打印跳过提示，正常退出 |
| 2 | 凭证缺失检查 | 环境变量 | `LINE_CHANNEL_ACCESS_TOKEN` / `LINE_CHANNEL_SECRET` 为空 | 打印错误并 `sys.exit(1)` |
| 3 | 配置 LINE 通道 | `POST /openclaw/set-channel` | `channel=line`, `keys=[channel_access_token, channel_secret]` | 200 |
| 4 | 查询确认 | `GET /openclaw/channels?id=<db_id>` | 响应 channels 中包含 `line` | 断言通过 |
| 5 | Hermes 服务可用 | `GET /openclaw/check-openclaw-port?id=<db_id>` | `running=true` | 断言通过 |
| 6 | Channel 连接状态 | 同上 | `channelSummary.enabled >= 1`（软检查，缺失字段则跳过） | 断言通过或软跳过 |
| 7 | 删除 LINE 配置 | `POST /openclaw/del-channel` | `channel=line` | 200 |
| 8 | 查询确认已删除 | `GET /openclaw/channels?id=<db_id>` | 轮询 6 次确认 `line` 从列表移除 | 断言通过 |
