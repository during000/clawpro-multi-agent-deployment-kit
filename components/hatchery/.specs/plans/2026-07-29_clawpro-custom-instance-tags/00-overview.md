## 关键决策备忘

- TAPD 长 ID `1020422209136340282`，短 ID `136340282`，仅改后端 API，不改前端。
- 用户端 `POST /openclaw/create` 新增 form 字段 `tags`，值为 JSON 数组字符串；管控端 `POST /admin/instances/create` 新增 JSON 数组字段 `tags`。
- 标签元素统一使用小写 JSON 字段 `key` / `value`，支持多个。
- 自定义标签的键值合法性、账号归属、数量等业务约束由最终 `RunInstances` 统一校验，避免本地规则与腾讯云漂移；本地只校验用户端 `tags` 的 JSON 结构。
- 请求传入至少一个自定义标签时，RunInstances 标签校验错误返回 400；未传自定义标签时沿用原有 500 行为。
- 命中的默认标签与自定义标签合并；同 key 冲突时自定义标签优先。自定义标签内部重复 key 不静默改写，交由 RunInstances 按云端规则拒绝。
- 用户端和管理员端继续共用 `createInstance` 主流程，不新增数据库字段或持久化逻辑。

## 风险速览

| # | 风险 | 严重度 | 缓解 |
|---|------|-------|------|
| 1 | 本地复制腾讯云标签校验导致规则漂移 | 高 | 仅做结构解析，键值和账号归属由 RunInstances 权威校验 |
| 2 | 自定义标签与默认标签同 key 导致云端重复键错误 | 高 | 合并时自定义标签覆盖同 key 默认标签 |
| 3 | 两个创建入口解析方式不同导致行为分叉 | 中 | 统一转换为 `createInstanceTag` 后进入同一注入函数 |
| 4 | 新参数未进入 OpenAPI/集成测试 | 中 | 同步 `docs/API.md` 并更新两个入口的 IT 参数校验 |
