## 更新清单

- `POST /openclaw/create` 参数表新增 form 字段 `tags`，说明 JSON 数组字符串格式。
- `POST /admin/instances/create` 参数表新增 `tags`、`tags[].key`、`tags[].value`，请求示例加入多标签。

- 用户端/管控端 IT 脚本分别补充非法结构、完整参数和嵌套未知字段校验。
