## IT 中发现并修复的问题

1. **调整锁冲突错误码错误**
   admin stop 与 restart-gateway 在活动调整期间错误返回 HTTP 500。已分别修复
   `controller/instance_power.go` 和 `controller/admin_instances.go`，统一返回 409；
   `TestAdjustmentSurfaceContract_U18SharedGuardsRejectBeforeResolution` 增加回归断言并通过 race。

2. **`UnsupportedOperation` 被误判为“云操作进行中”**
   `mapAdjustmentCloudError` 原先用宽泛的 `"operation"` 子串匹配，导致腾讯云
   `UnsupportedOperation.InstanceStateStopped` 永久映射为 `cvm_operation_in_progress`。
   已在 `controller/instance_adjustment_cloud.go` 收窄为明确的
   `operationinprogress`/`operation in progress`，精确错误现在经在线路径映射为
   `online_resize_not_supported`。真实账号复验通过。

3. **Python 3.9 E2E 兼容性**
   `test/scripts/helpers/client.py` 与 `test/scripts/helpers/instance.py` 增加
   postponed annotations；新增 E2E 脚本按 Python 3.9 编译通过。

4. **真实账号能力条件**
   当前测试实例在线系统盘扩容不受支持。E2E 显式记录该能力并继续验证离线及已停止写路径，
   不把拒绝当成在线写成功，也不更改生产请求语义。
