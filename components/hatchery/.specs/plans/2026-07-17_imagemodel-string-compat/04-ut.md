# 单元测试：imageModel 格式兼容性验证

## 测试方式

由于改动的是 shell 脚本中的 jq 表达式（非 Go 代码），采用 shell 测试脚本验证：构造测试 JSON，提取修改后的 jq 表达式片段，运行 `jq` 命令验证输出。

测试脚本：`test/scripts/test_imagemodel_compat.sh`

## 用例与结果

| # | 用例 | 输入 imageModel | 操作 | 预期 | 结果 |
|---|------|----------------|------|------|------|
| TC-01 | set_model string | `"old-ref"`（字符串） | set primary="new-ref" | 重置为对象 `{"primary":"new-ref","fallbacks":[]}` | ✅ PASS |

| TC-05 | switch_model string | `"old-ref"`（字符串） | switch primary="new-ref" | 同 TC-01 | ✅ PASS |

- 额外覆盖了 remove 场景中 primary 匹配/不匹配的分支（TC-08 vs TC-08b）
