## 关键决策备忘

> **跨阶段共享的关键上下文**。仅记录影响后续步骤的决策，避免恢复时还要翻阅历史阶段文件。

- TAPD 需求：1020422209135809941「【clawpro】免登陆跳转链接功能」
- 申请接口使用与其它 `/admin` API 相同的 `requireAdmin` 鉴权，通过 `user_id` 指定当前租户任意有效用户
- 跳转凭证有效期 2 分钟，数据库仅存 SHA-256 摘要，以条件删除保证仅成功消费一次
- 功能白名单复用全局 `FeatureAllowlist`，每个 feature type 的空表策略在 model 集中配置；`passwordless-login` 空表默认关闭，只有明确配置的 tenant identifier 放行
- 链接使用可信 TenantSnapshot.Domain，格式为 `/passwordless-login#passwordless_login_token=...`
- `../openclaw-enterprise-fronted` 新增公开落地页，经 `/api/auth/passwordless-login` 消费后完整刷新并复用 `authApi.check()` 同步用户

## 风险速览

| # | 风险 | 严重度 | 缓解 |
|---|------|-------|------|
| 1 | 跳转凭证泄露后被抢先消费 | 高 | 短有效期、单次消费、避免在日志和响应中暴露额外敏感信息 |
| 2 | 白名单配置错误导致越权 | 高 | `passwordless-login` 使用空表默认拒绝策略，申请与消费均检查；删除最后一条记录会关闭全部租户 |
| 3 | 前端仓库处于 detached HEAD 且有用户修改 | 中 | Implement 前基于 `c0f409e6` 建立任务分支，保留并不触碰现有 `Dockerfile` 修改 |
