## 关键决策备忘

> **跨阶段共享的关键上下文**。仅记录影响后续步骤的决策，避免恢复时还要翻阅历史阶段文件。

- STS 刷新 `Update("sts_expired_at", ...)` 会自动更新 `updated_at`，直接重置 NoFiles 分支的 12 小时窗口。
- 推荐新增 `activated_at`：新会话从 active 时刻计时；存量 NULL 记录回退 `created_at`，避免继续依赖已污染的 `updated_at`。
- STS 字段写入同时改为不刷新 `updated_at` 的方式；有对话文件时继续使用 mtime，不改变现有语义。
- `activated_at` 使用可空 `datetime(3)`，不回填历史数据；增量迁移必须先于应用发布，不新增索引。
- 激活状态与 `activated_at` 同一次更新落库；本次不引入对所有 active 会话生效的绝对 `created_at` 超时。
- `RefreshDoctorSTS` 使用 `UpdateColumn` 且检查数据库错误；NoFiles 日志与判断使用同一有效激活时间。
- 为两个数据库更新失败分支补充单测，本次 20 个可执行增量行覆盖率为 100%。
- MySQL 8.0.46 验证增量迁移与全量 init 的 `activated_at` 定义一致，存量行保持 NULL。
- 2026-07-20 的旧任务处理远端探测失败兜底，与本次根因不同，不复用已完成任务目录。
