## 运行命令

```bash
# K8s 连通性（只读）
kubectl cluster-info --request-timeout=5s

# 本地临时 MySQL 8.0.46
docker run --rm --name clawpro-doctor-migration-it \
  -e MYSQL_ALLOW_EMPTY_PASSWORD=yes -d mysql:8.0.46

# 在 hatchery_legacy 中创建旧版 doctor_sessions、插入存量 active 数据，
# 然后执行增量迁移
docker exec -i clawpro-doctor-migration-it \
  mysql -uroot hatchery_legacy \
  < sql/0730-add-doctor-session-activated-at.sql

# 在 hatchery_fresh 中执行全量初始化 schema
docker exec -i clawpro-doctor-migration-it \
  mysql -uroot hatchery_fresh \
  < sql/init.sql

# 验证文档仍可生成 OpenAPI
make openapi

# 测试后停止临时容器；因使用 --rm，容器已自动删除
docker stop clawpro-doctor-migration-it
```
