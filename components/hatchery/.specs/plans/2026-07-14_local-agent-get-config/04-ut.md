## 四、实现中修正的点（与 Plan 偏差）

1. **gorm tag 修正**：联合唯一索引原写 `index:idx_lacc_ident_type,unique,priority:1`，SQLite AutoMigrate 下被解析成 `config_type` 单列唯一约束（导致测试报 `UNIQUE constraint failed: config_type`）。改为 `uniqueIndex:idx_lacc_ident_type,priority:1`(Identifier) + `priority:2`(ConfigType)，联合唯一索引正确生效。MySQL 端 init.sql / 增量迁移的 `UNIQUE KEY idx_lacc_ident_type (identifier, config_type)` 原本就正确，无需改。
2. **测试 Store 初始化**：项目惯例是每个测试函数体显式 `Store = sessions.NewCookieStore(...)` + cleanup 恢复（非 helper 内初始化），改用 `setupGetConfigTest` helper 统一初始化，避免全局 `Store` 竞态。
3. **租户隔离测试归属**：从 controller 移到 model（见上）。
