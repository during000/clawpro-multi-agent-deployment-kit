## 执行结果

当前无法执行真实 CVM → SMH → 目标 CVM 的端到端迁移，未将其误报为通过。

已新增自动化用例：

```text
test/scripts/openclaw_instance/test_instance_migration_hermes.py
```

该用例在集成环境中创建真实 Hermes 实例，并覆盖：

1. 实例记录 `agent_type=hermes`；
2. export 返回脚本包含 `.hermes`、Hermes 专属兼容开关、精确排除路径、业务树指纹、
   根目录告警分类和 `tar tf` 验包；
3. 未执行导出脚本时 status 返回 `file_ready=false/can_import=false`；
4. 未上传迁移包时 import 返回 400；
5. 设置 `HERMES_MIGRATION_E2E=1` 后，通过 TAT 在 `.hermes` 写入唯一标记并执行 export；
   确认 SMH 文件就绪后删除标记、触发 import、等待状态 done，再读取标记验证恢复；
6. export/TAT 完整请求响应不进入测试帧日志，避免泄漏临时 SMH 凭证；异常和成功路径均清理测试实例。

首次在集成环境执行时，前置检查使用动态管理员 API Token 请求非 OpenAPI 的
`/admin/smh/config`，服务端按权限设计返回 401。用例已改用测试框架提供的
`BOOTSTRAP_ADMIN_TOKEN`；服务端鉴权和业务代码未修改。

本地已完成 Python 语法检查和 fake response 契约自检，4 个测试函数全部通过。当前机器虽存在
默认 Kubeconfig，但 Docker 不可用，且未注入测试所需腾讯云 AK/SK，也无法预检部署后的 SMH
配置，因此没有执行会创建真实 CVM 的命令。

集成环境运行命令：

```bash
make test IMAGE=<镜像> TEST_ARGS="--ak <AK> --sk <SK> --run openclaw_instance/test_instance_migration_hermes.py"
```

执行真实迁移闭环（建议单脚本超时至少 30 分钟）：

```bash
HERMES_MIGRATION_E2E=1 make test IMAGE=<镜像> \
  TEST_ARGS="--ak <AK> --sk <SK> --script-timeout 30m --run openclaw_instance/test_instance_migration_hermes.py"
```

已执行本地脚本级集成替代验证：直接运行仓库中的 `scripts/export_migration.sh`，以 fake
tar/curl 注入被排除运行时文件变化、非 Hermes 根目录告警、普通文件告警、根级业务项
新增、嵌套业务文件替换、损坏归档和正常成功七种情形，并验证业务树指纹、上传调用、
日志持久化、失败阶段和凭证脱敏。全部通过。

## 发布前人工验收

1. 在 Hermes 测试实例打开 Agent 面板并保持活动。
2. 发起迁移导出，确认日志出现根目录元数据变化提示、归档校验通过且 SMH 上传完成。
3. 在目标实例导入并检查会话、配置、技能等用户数据。
4. 检查源实例 `~/.hermes/logs/migration_export_*.log`，确认阶段信息完整且无 token/header/URL。
5. 人为新增或替换根级/嵌套业务文件时验证导出失败且不会上传。
