## 覆盖率

新增代码为 `startProbeChecker` + `runProbeChecker` 两函数（约 90 行），新增用例覆盖：
- `TestCleanupDoctorSessions_探测持续失败但超12小时仍强制结束`：连续探测失败 + 超 12h → 兜底结束（核心路径）
- `TestRunProbeChecker_探测恢复成功则退出`：探测成功 → 退出不结束
- `TestRunProbeChecker_Context取消则退出`：ctx 取消 → `select/case <-ctx.Done()` 退出不泄漏
- `TestCleanupDoctorSessions_获取失败则启动验证协程`：mtime 失败 → 主循环改走 `startProbeChecker`
- `TestCleanupDoctorSessions_探测失败但未超12小时不应被误伤`：连续失败但未超时 → 不误杀
- `TestCleanupDoctorSessions_DoctorInstanceID为空但超12小时` / `关联实例不存在但超12小时`：原兜底分支路径

核心路径（兜底结束 / 探测恢复 / context 取消 / 未超时退出 / DB 持续失败退出）均有用例覆盖。
