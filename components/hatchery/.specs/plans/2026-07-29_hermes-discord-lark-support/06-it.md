# 06. IT — 集成测试

---

## 背景

原任务在首次推进时将 IT 标记为「跳过：无新 API 接口」。
后续 Review 发现：新增的 discord / lark 通道虽然复用既有 set-channel / del-channel API，
但属于**新增通道类型在 hermes 白名单中的端到端验证**，需要集成测试覆盖配置 → 查询 → 删除完整流程，
以保证脚本层（set_channel_hermes.sh / del_channel_hermes.sh）与 API 层契约一致。

本次补齐集成测试用例。

## 新增用例

| TC | 文件 | 通道 | 凭证参数 | 站点范围 | 说明 |
|----|------|------|---------|---------|------|
| TC-H4.6 | `test/scripts/channel/test_discord_channel_hermes.py` | discord | `bot_token` + `user_id` | overseas-only | Discord 不支持通配符，必须传 user_id |
| TC-H4.7 | `test/scripts/channel/test_lark_channel_hermes.py` | lark | `app_id` + `app_secret` | overseas-only | Lark 复用 feishu 协议，脚本层设 FEISHU_DOMAIN=lark |

### 用例流程（两用例一致，仿 TC-H4.2~H4.5 既有模式）

1. Setup：创建模型 + 用户 + hermes 实例 + 绑定模型
2. 步骤 1：配置通道（`POST /openclaw/set-channel`，传对应凭证参数）
3. 步骤 2：查询确认通道存在于配置中（`GET /openclaw/channels`）
4. 步骤 3：验证 hermes 服务可用性（`GET /openclaw/check-openclaw-port`）
5. 步骤 3b：软检查 hermes-gateway channel 连接状态（`expect_hermes_channel_connected`）
6. 步骤 4：删除通道（`POST /openclaw/del-channel`）
7. 步骤 5：轮询确认通道已从列表移除

### 站点范围处理

discord / lark 均为 overseas-only 通道（`ai_channel.go` 中 `ChannelScopeOverseas`）。
测试用例在非海外站点自动跳过（通过 `is_overseas_site()` 判断），避免在国内站点误报失败。

### Lark 特殊处理

Lark 复用 feishu 的配置字段（`FEISHU_APP_ID` / `FEISHU_APP_SECRET` / `FEISHU_DOMAIN=lark`），
gateway 侧可能以 `lark` 或 `feishu` 为 key 显示通道。删除时 `del_channel_hermes.sh` 会清理所有
`FEISHU_*` 变量。因此查询确认与删除确认步骤同时检查 `lark` 和 `feishu` 两个 key。

## Helpers 变更

| 文件 | 变更 |
|------|------|
| `helpers/hermes.py` | `HERMES_WHITELIST_CHANNELS` 补 `discord`、`lark`（供 TC-H4.1 白名单断言使用） |
| `helpers/channel.py` | `SITE_SCOPED_CHANNELS` 补 `"lark": {"overseas"}`（与后端 `ChannelScopeOverseas` 对齐；discord 已有） |
| `helpers/config.py` | `_ChannelCredentials` 新增 `DISCORD_BOT_TOKEN` / `DISCORD_USER_ID` / `LARK_APP_ID` / `LARK_APP_SECRET` |

## 覆盖的 API

两用例覆盖的接口与既有 TC-H4.2~H4.5 一致，差异在于通道类型与凭证参数：
- `POST /openclaw/set-channel`（新增参数组合：discord 的 `user_id`；lark 的 `app_id`+`app_secret`）
- `GET /openclaw/channels`
- `GET /openclaw/check-openclaw-port`
- `POST /openclaw/del-channel`
