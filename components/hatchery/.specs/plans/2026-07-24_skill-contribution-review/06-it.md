## 二、K8s 端到端测试（待 CI 执行）

以下测试需要在具备 K8s 集群和腾讯云凭证的 CI 环境中执行：

```bash
# 构建并推送镜像
make release
docker push <registry>/hatchery:<tag>

# 运行集成测试
make test IMAGE=<registry>/hatchery:<tag> BASE_BRANCH=origin/master \
  TEST_ARGS="--ak xxx --sk xxx --report-dir ./test-report"
```

## 三、风险评估

| # | 风险 | 缓解 |
|---|------|------|
| 1 | 员工提交技能需 COS/SMH 上传，集成测试需真实 SMH 环境 | IT 脚本需 `requireSMHEnabled` 通过，使用测试环境 SMH |
| 2 | 通知发送需管理员用户存在 | IT 脚本需先创建管理员用户 |
| 3 | 审计日志需 WithAudit 中间件生效 | IT 脚本验证 `audit_logs` 表有对应记录 |
