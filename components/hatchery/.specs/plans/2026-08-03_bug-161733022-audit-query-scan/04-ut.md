# 04. UT — 单元测试（username 精确查询 v4）

## 验证结论

- `username` 默认精确、`fuzzy=1` 显式模糊、`user_id` 精确筛选及组合条件均通过 controller 定向 race。
- 模型定向 race 通过，SQLite AutoMigrate 能创建 `user_id`、`(identifier,user_id)`、`(identifier,username)`、`(identifier,resource_id)` 索引。
- 全量非 race、`go vet`、开发态 race 构建和 release 构建均通过。
- 全量 race 仍只命中 `task/TestCheckAllAgents_SecureFirstBootTriggered_CustomImage` 的既有全局 DB 竞态；单独复现取得明确读写栈，与本任务审计代码无关。
- `staticcheck` 本机未安装，未执行；未以其他检查冒充结果。
