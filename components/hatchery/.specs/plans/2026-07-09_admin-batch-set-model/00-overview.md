## 关键决策备忘

> **跨阶段共享的关键上下文**。仅记录影响后续步骤的决策，避免恢复时还要翻阅历史阶段文件。

- 需求范围按初始讨论确认：管控端 agent 列表支持批量覆盖模型配置。
- 批量接口语义是覆盖目标实例模型集合：顶层模型为 primary，`fallbacks` 为 fallback 列表；不是 add-model。
- `/openclaw/set-model` 成功响应保持 `provider` / `model_id`，不破坏旧接口兼容。
- `context_len` 仅补 `strconv.Atoi` 错误检查；`<=0` 仍按既有语义回退默认值，不提取常量、不扩大到其他入口。
- 自定义 Agent 类型按兼容运行时执行脚本；无兼容运行时时按单项失败。
- 新增 OpenAPI operation 需要 `test/scripts/` 轻量集成测试覆盖；不要求在本地直接跑完整 K8s/CVM IT。
- 完整 IT 中通道/模型生命周期外部依赖失败项由用户确认直接跳过，不阻塞后续 Review / Commit。
