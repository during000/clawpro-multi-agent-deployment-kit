## 未覆盖行

覆盖率脚本输出了未覆盖的变更行，主要集中在以下几类：

- `controller/admin_instances.go`
  - 部分分页/列表辅助分支与错误分支。
  - 批量接口中极端 DB 查询失败、目标构造边界、部分请求级错误分支。
- `controller/openclaw_model.go`
  - 自定义模型字段校验的部分异常分支。
  - DB 回滚失败后的日志分支。
  - TAT 失败后不同错误类型分派的部分分支。
  - 当前 review 添加的 `context_len` 非整数错误返回分支未单独新增 UT。
- `main.go`
  - 路由注册行无法通过 handler 单测直接计入覆盖。

未覆盖原因：

- 多数为防御性错误分支、日志分支、DB 底层错误或外部脚本失败的罕见组合。
- 本次核心 P0 用例均已覆盖并通过。
- 增量覆盖率 66.9%，高于 CODEBUDDY/CI 默认 60% 阈值。
