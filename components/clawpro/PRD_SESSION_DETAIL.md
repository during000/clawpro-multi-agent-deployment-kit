# 会话详情页面 PRD

## 1. 页面概述

会话详情页面是管控端会话管理的核心功能页面，用于展示单个会话的完整信息、成本分析和对话链路。用户可以从会话管理页面的会话列表中下钻进入此页面，详细了解每一轮对话的成本、Token 消耗、模型使用情况等。

**页面路径**：管理后台 → 会话管理 → 点击会话 → 会话详情页面

---

## 2. 页面结构

### 2.1 页面标题区域

**功能**：展示会话的基本标识信息

**组成部分**：
- **会话名称**（主标题）：会话的主题或标题，字体加粗，字号较大
- **会话 ID**（副标题）：唯一标识符，格式为 "会话 ID: {sessionId}"，字体较小，颜色较浅

**交互**：
- 支持返回按钮，点击返回会话管理列表页面
- 支持复制会话 ID 功能

---

### 2.2 顶部指标卡区域

**功能**：快速展示会话的关键指标

**指标卡片**（4 个卡片，水平排列）：

#### 2.2.1 会话成本卡片
- **标签**：会话成本
- **数值**：总费用（如 $0.2743）
- **单位**：美元（$）
- **图标**：蓝色圆形图标
- **说明文字**：total_cost
- **计算方式**：所有轮次的成本总和

#### 2.2.2 平均轮次成本卡片
- **标签**：平均轮次成本
- **数值**：每轮平均费用（如 $0.0076）
- **单位**：美元（$）
- **图标**：橙色圆形图标
- **说明文字**：avg_cost_per_round
- **计算方式**：总成本 / 总轮次

#### 2.2.3 TOKEN 总量卡片
- **标签**：TOKEN 总量
- **数值**：总 Token 数（如 1.95M）
- **单位**：Token（支持 K/M 单位换算）
- **图标**：绿色圆形图标
- **说明文字**：total_tokens
- **计算方式**：所有轮次的 Token 总和

#### 2.2.4 会话轮次卡片
- **标签**：会话轮次
- **数值**：对话轮数（如 63）
- **单位**：轮
- **图标**：蓝绿色圆形图标
- **说明文字**：total_rounds
- **计算方式**：对话消息对数

---

### 2.3 图表区域

**功能**：可视化展示会话的成本和 Token 消耗趋势

#### 2.3.1 每轮成本图表
- **图表类型**：柱状图（Bar Chart）
- **标题**：每轮成本
- **X 轴**：轮次（1, 2, 3, ..., N）
- **Y 轴**：成本（美元，$）
- **数据**：每一轮对话的成本
- **颜色**：蓝色柱子
- **交互**：
  - 悬停显示具体数值
  - 支持放大/缩小视图
- **接口**：[待补充] 获取每轮成本数据接口

#### 2.3.2 Token 流量图表
- **图表类型**：堆叠柱状图（Stacked Bar Chart）
- **标题**：Token 流量
- **X 轴**：轮次（1, 2, 3, ..., N）
- **Y 轴**：Token 数量
- **数据**：
  - 输入 Token（蓝色）
  - 输出 Token（橙色）
- **交互**：
  - 悬停显示输入和输出的具体数值
  - 支持放大/缩小视图
  - 支持切换视图（堆叠/并排）
- **接口**：[待补充] 获取 Token 流量数据接口

---

### 2.4 交互链表区域

**功能**：展示完整的对话历史和每条消息的详细信息

**表格结构**：

| 列名 | 说明 | 数据类型 | 示例 |
|------|------|--------|------|
| 时间 | 消息创建时间 | 日期时间 | 2026-03-04 13:32:00 |
| 角色 | 消息发送者角色 | 标签（user/assistant/system） | user, assistant |
| 内容 | 消息内容摘要 | 文本（支持截断） | "你能干啥" |
| 模型 | 使用的模型名称 | 文本 | deepseek-v3.2 |
| 停止原因 | 消息生成的停止原因 | 标签 | stop, length, error |
| INPUT | 输入 Token 数 | 数字 | 17K |
| OUTPUT | 输出 Token 数 | 数字 | 315 |
| CACHE R/W | 缓存读写情况 | 文本 | 0/0 |
| TOKENS | 本轮总 Token 数 | 数字 | 17K |
| 成本 | 本轮成本 | 金额 | $0.0024 |
| 耗时 | 本轮处理耗时 | 时间 | 13.6s |

**表格功能**：
- **分页**：支持分页显示，每页显示 10/20/50 条记录
- **排序**：支持按序号、成本、耗时等列排序
- **搜索**：支持按内容、模型、角色筛选
- **展开详情**：点击行可展开查看完整消息内容
- **导出**：支持导出表格数据为 CSV/Excel

**交互**：
- **行悬停**：高亮显示当前行
- **点击行**：展开/收起详细信息
- **内容截断**：超长内容显示省略号，悬停显示完整内容
- **角色标签**：不同角色使用不同颜色标签区分

## 4. 交互流程

### 4.1 页面加载流程
1. 用户从会话管理列表页面点击某个会话
2. 页面加载会话 ID，调用会话详情接口获取基本信息
3. 同时并行调用成本趋势、Token 流量、对话链表三个接口
4. 页面渲染顶部指标卡、图表和表格

### 4.2 表格交互流程
1. 用户可以通过分页按钮切换页码
2. 用户可以点击列标题进行排序
3. 用户可以使用搜索/筛选功能过滤数据
4. 用户可以点击表格行展开查看完整消息内容

### 4.3 返回流程
1. 用户点击返回按钮
2. 页面返回会话管理列表，保留之前的筛选和排序状态

## 5. 设计规范

### 5.1 颜色规范
- 指标卡图标：蓝色（#007AFF）、橙色（#FF9500）、绿色（#34C759）、蓝绿色（#00C7BE）
- 图表颜色：蓝色（#007AFF）、橙色（#FF9500）
- 表格行颜色：白色背景，悬停时浅灰色背景

### 5.2 字体规范
- 页面标题：24px，加粗
- 副标题：14px，浅灰色
- 指标卡标签：12px，浅灰色
- 指标卡数值：28px，加粗
- 表格文本：14px

### 5.3 间距规范
- 页面顶部边距：32px
- 指标卡之间间距：16px
- 图表与表格之间间距：24px
- 表格行高：48px

## 6. 错误处理

### 6.1 数据加载失败
- 显示错误提示信息
- 提供重试按钮

### 6.2 会话不存在
- 显示"会话不存在"提示
- 提供返回列表按钮

### 6.3 网络超时
- 显示超时提示
- 提供重试按钮

---

## 7. 性能优化

- 使用虚拟滚动优化大数据表格渲染
- 图表使用防抖处理窗口大小变化
- 接口数据缓存，避免重复请求
- 图表数据分页加载，避免一次性加载过多数据
