D-03 让你确认的组件：强切换 vs 弱切换

卡片让你确认的，是用户端（Tenant）两种「切换」交互到底要不要拆成两个独立组件规范。
下面是项目源码 client/src/components/ui/segment.tsx 里它们真实的样子（可点击）：

强切换 Tenant Capsule Tabs（胶囊滑块） 主切换
视觉重、有白色滑块背景 + 阴影。用于主导航 / 主分类切换（我的 Agent / 技能广场 / 模型额度、子分类筛选）。组件：CenterTabs / TenantSegment。
容器 h-36 / radius 9999 / bg rgba(219,221,228,0.32) · 滑块 #FFF + border #CDD4DC + shadow 0 1px 4px · active #020617 / 500 · inactive #334155 / 400
一句话区分
维度强切换 · Capsule Tabs弱切换 · Text Switch
视觉白色胶囊滑块 + 阴影，分量重纯文字 + / 分隔，分量轻
语义主导航 / 主分类，页面级切换辅助开关，主操作旁的次要切换
典型位置顶部导航中央、页内大分类列表右上角「普通 / 多组织」
会不会喧宾夺主本身就是主角不能盖过主操作，所以做轻
卡片选项 A（推荐）就是「拆成这两套规范」——把上面两个组件分别立为 Tenant Capsule Tabs 与 Tenant Text Switch，各管各的语义；B 是只留胶囊版，弱切换也复用它；C 是不拆、页面自己看着选。
