04 / Visual Findings

初步视觉判断与优化候选

当前比较稳的部分

  • 16px 已成为导航、按钮、菜单的主规格。
  • Agent 卡片状态 SVG 语义明确，和业务状态绑定紧。
  • 模型额度统计 icon 容器清晰，适合作为数据类基准。

需要观察的混用

  • lucide、自定义 SVG、图片头像、字母头像、状态 SVG 并存。
  • 同类容器存在 32px、36px、40px、48px 多规格。
  • 灰色使用含 muted、gray 与 hex token，观感可能不一致。

建议优先优化

  • 先统一“功能入口容器”：数据 32px、分类 40px、头像 48px。
  • 技能广场优先梳理小图标密度与状态色。
  • 把 12/14/16px 操作 icon 的使用边界写入规范。
