需要统一： 1）减少 `text-gray-*`，迁移到 v2 色阶；2）任意值字号收敛到 T1/T10 等明确组件；3）inline `fontFamily` 改为 `font-sans/font-din/font-mono/font-en`；4）`text-xs` 与 `text-sm` 按语义拆分，不再作为万能字号。

5. 落地建议

建议先新增基础组件，再按用户端核心路径渐进替换，避免一次性全量重构。

  1. 新增基础组件：创建 client/src/components/ui/Typography.tsx，定义 TenantHeroTitle、TenantPageTitle、PanelTitle、BodyText、MetaText、StatNumber 等组件。
  2. 先迁移共享组件：从 components/topnav/**、components/agent/** 开始，收益最大且能带动页面统一。
  3. 再迁移核心页面：优先处理 MyOpenClaw、OpenClawDetailGuide、SkillSquare、ModelQuota 等用户高频路径。
  4. 保留特殊场景：帮助文档 Markdown 可用单独的 prose 映射；聊天内容区可保留内容型排版规则，但标题、按钮、Meta 信息仍接入组件。
  5. 建立检查清单：新增页面禁止裸写大段 text-sm/text-xs，除非能明确映射为某个 Typography 组件的变体。

6. 建议组件 API 草案

组件 API 保持轻量，允许通过 as 控制标签，通过 className 做少量布局补充。
