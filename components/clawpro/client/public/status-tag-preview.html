6. 禁止用法（旧 API 反例对照）

下列形态全部已删除，老代码迁移时一律重写为 <StatusTag variant="*">。

❌ mode="fill" · 浅底彩色胶囊

运行中 异常 全部用户
语义混在状态/分类之间，整列色块密度过高。

✅ 状态 → StatusTag text；分类 → Badge

运行中 异常 全部用户
"全部用户" 是分类，走 Badge color="blue"。

❌ mode="soft" · 浅底+浅边框胶囊

企业技能 实验技能
"企业技能 / 实验技能" 是分类，不是状态。

✅ 改用 Badge 或宿主 Tag

企业技能 实验
分类语义 → Badge color="purple|orange"；不允许用 StatusTag 拼装。

❌ 14px / dot 旧形态

运行中 运行中
14px 与表格 12px 数据列不齐；dot 已废弃。

✅ 12px Medium · 仅彩色文字

运行中 运行中
需要 dot 语义 → 套外层 1.5px 圆点，组件本体不渲染圆点。

❌ 用 StatusTag 表达版本 / 范围 / 分类

v2.1.0 企业版 公共
这些都是"标签"语义，不是"状态"。

✅ 用 Badge 表达"标签"

v2.1.0 企业版 公共
用户语义里出现"标签 / 版本 / 分类" → 一律 Badge。

❌ 给 StatusTag 加底色 / 圆角

运行中 失败
破坏唯一形态。想要"色块" → 直接换 Badge。

✅ 保持纯文本
