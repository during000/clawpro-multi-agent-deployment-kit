8. Do / Don't

✓ Do

  • 表格整体使用 12px 口径（单元格正文和表头统一）
  • 操作列统一品牌蓝文字按钮 + 24px 间距
  • 空态放在表体内 <td colSpan> 纯文字
  • 选中状态用 Checkbox 表达，不给行加底色
  • 列多时用横向滚动 + 固定列
  • 表头行禁止 hover 变色
  • 页脚数量左对齐、分页器右对齐

✗ Don't

  • 不用原生 table + 临时 class 拼装
  • 不在操作列混入多种颜色表达危险级别
  • 不给表格空态包大卡片或放插画
  • 不手写 sticky + bg-white 模拟固定列
  • 不给选中行加蓝底高亮
  • 不在紧凑版缩减横向 padding
  • 不用 variant="white" 在白色容器/弹窗内

9. QA Checklist

  • ☐ 表头、表体、分页是同一个模块
  • ☐ 表格字号统一 12px 口径
  • ☐ 操作列使用品牌蓝文字按钮，间距 24px
  • ☐ 操作列删除按钮不用红色
  • ☐ 空态在表体内 <td colSpan> 纯文字，无插画
  • ☐ 选中行无背景高亮
  • ☐ 表头行不 hover 变色
  • ☐ 页脚：总数左 + 分页器右
  • ☐ 标准版和紧凑版横向 padding 都是 px-4
  • ☐ 固定列无手写 sticky，无灰白割裂
  • ☐ 表格内状态列只用纯文字变色，不用带底色标签
  • ☐ fallback 使用 var(--cp-*) CSS variable
  • ☐ 跨仓 fallback 可独立落地
