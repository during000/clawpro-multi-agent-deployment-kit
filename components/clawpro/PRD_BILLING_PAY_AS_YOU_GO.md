# 需求单：按量计费 + 关机不收费

| 项 | 内容 |
|---|---|
| 创建人 | petzhou |
| 创建时间 | 2026-06-04 |
| 涉及端 | 管控端 + 用户端 |
| 涉及分支 | `feature/admin-pay-as-you-go` |

---

## 背景

当前平台 Agent 统一按"持续占用资源"模式收费，闲置不关机也照常计费，企业成本无法精细控制。本次需求引入**按量计费模式**，按量计费 Agent 关机后自动释放 CPU/内存并停止相关计费，实现"关机不收费"。

---

| # | 功能点 | 落地位置 |
|---|---|---|

## 需求点 1：资源管理页 — 计费模式配置

**页面入口**：管控端 → Agent 启动配置 → 资源管理（`/admin/resource-management`）

### 1.1 页面定位

- 标题：**资源管理**
- 副标题：统一管理企业内 Agent 的资源配置，当前支持计费模式配置，更多功能敬请期待。

### 1.2 计费模式模块

| 选项 | 标题 | 描述 |
|---|---|---|
| `subscription` | 包年包月 | 按固定周期收费，费用稳定可预期 |
| `payg` | 按量计费 | 按 Agent 运行时长收费，支持「关机不收费」模式 |

- 二选一卡片切换，选中后点「保存」生效
- 修改此项**不影响已启动的 Agent**，仅对后续新建 Agent 生效
- 不展示任何费用金额
- 不展示关机不收费说明

### 1.3 数据存储

通过 `agentBillingStore.ts` 双层存储：
- **启动模板默认值**（`getDefaultLaunchBillingMode / setDefaultLaunchBillingMode`）：影响新建 Agent
- **per-Agent 覆盖**（`getAgentBillingMode / setAgentBillingMode`）：兼容历史运行时调整

## 需求点 2：Agent 详情抽屉 — 计费模式展示

**位置**：管控端 Agent 列表 → 点击 instanceId 打开详情抽屉 → 「名称/ID」与「已应用模型」之间

### 2.1 展示内容

| 计费模式 | 图标 | 标题 | 描述 | 状态徽标 |
|---|---|---|---|---|
| 按量计费 | Clock（蓝色底） | 按量计费 | 按 Agent 运行时长收费，支持「关机不收费」 | 运行中→绿色「计费中」；已关机→灰色「已关机」 |
| 包年包月 | Wallet（紫色底） | 包年包月 | 按固定周期收费，费用稳定可预期 | 无 |

- 按量计费 + 有 `runningMinutes` 时额外显示：「累计运行时长 X 小时 Y 分钟」

### 2.2 数据源

`getClawBillingMode(claw)` 三层兜底：
1. `claw.billingMode`（Agent 自身字段，权威源）
2. `getAgentBillingMode(claw.id)`（per-Agent 本地存储）
3. `getDefaultLaunchBillingMode()`（启动配置默认值）

## 需求点 3：关机功能 — 单机关机

### 3.1 触发入口

| 端 | 入口 | 条件 |
|---|---|---|
| 管控端 | Agent 列表操作列「关机/开机」按钮 | 运行中→关机；已关机→开机 |
| 用户端 | 「我的 Agent」卡片更多菜单 → 关机/开机 | 同上 |

### 3.2 关机确认弹窗（按量计费与包年包月完全一致）

```
┌───────────────────────────────────────────┐
│ 确认关机                                   │
├───────────────────────────────────────────┤
│ 关机后该 Agent「xxx」将无法使用，          │
│ 直到重新开机。                             │
├───────────────────────────────────────────┤
│                      [取消]  [确认关机]    │
└───────────────────────────────────────────┘
```

- 无关机模式选择、无释放资源说明
- 按量计费 Agent 关机后，后端自动释放计算资源（CPU、内存）并停止相关计费
- 包年包月 Agent 正常关机
- toast 统一：`已关机 {name}` / `已开机 {name}`

### 3.3 开机弹窗

```
┌───────────────────────────────────────────┐
│ 确认开机                                   │
├───────────────────────────────────────────┤
│ 开机后该 Agent「xxx」将重新运行。          │
│ 确认开机吗？                               │
├───────────────────────────────────────────┤
│                      [取消]  [确认开机]    │
└───────────────────────────────────────────┘
```

## 需求点 4：关机功能 — 批量关机

### 4.1 按钮位置

管控端 Agent 列表顶部操作栏，「批量删除」按钮**右侧**。

### 4.2 按钮样式

- 图标：`PowerOff`，橙色描边
- 禁用时灰色 + cursor-not-allowed
- 非禁用时显示运行中 Agent 数量徽标

### 4.3 禁用规则

| 条件 | 状态 | tooltip |
|---|---|---|
| 未选中任何 Agent | 禁用 | 请先选择 Agent |
| 选中的 Agent 全部不在运行中 | 禁用 | 所选 Agent 均不在运行中，无需关机 |
| 其他 | 可用 | — |

> 不限制计费模式，按量计费和包年包月均可批量关机。

### 4.4 批量关机确认弹窗

```
┌───────────────────────────────────────────┐
│ 批量关机                                   │
├───────────────────────────────────────────┤
│ 您已选择 N 个运行中的 Agent，             │
│ 进行关机操作前，请确认：                   │
│                                           │
│ ┌─────────────────────────────────────┐   │
│ │ Agent1、Agent2、Agent3...           │   │
│ └─────────────────────────────────────┘   │
├───────────────────────────────────────────┤
│                      [取消]  [确认关机]    │
└───────────────────────────────────────────┘
```

- 顶部灰色区块展示选中 Agent 名称列表（最多 24px 高度，超出滚动）
- 无关机模式选择、无释放资源说明
- 确认后统一 toast：`已关机 N 个 Agent`

### 4.5 执行逻辑

- 所有选中的运行中 Agent 置为 `status: "shutdown"`
- 按量计费 Agent：后端自动释放 CPU/内存，停止计费
- 包年包月 Agent：正常关机
- 清空已选（`selectedIds`）
