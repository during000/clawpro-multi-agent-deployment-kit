# OpenClaw Enterprise 管控端核心页面 PRD

## 文档概述

本 PRD 详细说明管控端三个核心页面的设计和交互：**Tokens 监控（按会话）**、**运维观测**、**会话管理**。重点关注页面的图表展示、用户交互、以及 CLS 日志服务的集成。

---

### 核心图表和数据展示

#### 1. 指标卡片区域（顶部）

展示五个关键指标，帮助管理员快速了解全局 Token 消耗情况。

| 指标 | 说明 | 单位 | 数据来源 |
|------|------|------|--------|
| 总请求数 | 选定时间范围内的总请求数 | 个 | API: `GET /api/tokens/summary` |
| 输入 Tokens | 选定时间范围内的输入 Token 总数 | 个 | API: `GET /api/tokens/summary` |
| 输出 Tokens | 选定时间范围内的输出 Token 总数 | 个 | API /api/tokens/summary` |
| 总 Tokens | 输入 + 输出 Token 总数 | 个 | 计算字段 |
| 今日全局配额消耗 | 当日 Token 消耗占全局上限的百分比 | % | API: `GET /api/tokens/global-quota` |

**交互**：
- 指标卡片支持点击，可以跳转到对应的详情页面
- 当全局 token 上限设置为无限制时，消耗百分比显示为 0%，并在旁边显示"无限制"标签

#### 2. Token 消耗趋势图

展示最近 7 天或选定时间范围内的 Token 消耗趋势，帮助管理员了解消耗变化规律。

**图表类型**：折线图

**数据线**：
- 输入 Token（蓝色）
- 输出 Token（紫色）

**交互**：
- 支持鼠标悬停查看具体数值
- 支持点击图例切换显示/隐藏对应的数据线

#### 3. 会话列表（按会话标签页）

展示所有会话的详细信息，支持排序、筛选和下钻操作。

**表格列**：

| 列名 | 说明 | 数据来源 |
|------|------|--------|
| 会话名称 | 会话的显示名称 | API: `GET /api/tokens/by-session` |
| 渠道 | 会话所属的渠道（Feishu、QQ 等） | API: `GET /api/tokens/by-session` |
| 模型 | 会话使用的模型 | API: `GET /api/tokens/by-session` |
| Tokens | 会话消耗的 Token 数量 | API: `GET /api/tokens/by-session` |
| 成本 | 会话的成本（美元） | 计算字段 |
| 最后消息 | 会话的最后一条消息摘要 | API: `GET /api/tokens/by-session` |
| 更新时间 | 会话的最后更新时间 | API: `GET /api/tokens/by-session` |

**交互**：
- **排序**：点击列头可以按该列排序（升序/降序）
- **分页**：支持每页显示 10/20/50 条，支持跳页
- **下钻**：点击会话名称可以跳转到会话详情页面，查看会话的完整对话历史
- **筛选**：支持按渠道、模型、日期范围筛选

### CLS 日志服务管理

#### 开启 CLS 日志服务

**位置**：页面右上角，"CLS"按钮

**流程**：
1. 用户点击"CLS"按钮
2. 显示"开启 CLS 日志服务"的确认对话框（可选）
3. 调用 API: `POST /api/cls/enable`
4. 显示加载状态
5. 成功后显示 Toast 提示："CLS 日志服务已开启"
6. 更新页面状态，显示"关闭 CLS"按钮

**Toast 样式**：
- 背景色：绿色（#10b981）
- 图标：对勾
- 文字：白色
- 持续时间：3 秒

#### 关闭 CLS 日志服务

**流程**：
1. 用户点击"关闭 CLS"按钮
2. 显示确认对话框："确定要关闭 CLS 日志服务吗？"
3. 用户点击"确认"按钮
4. 调用 API: `POST /api/cls/disable`
5. 显示加载状态
6. 成功后显示 Toast 提示："CLS 日志服务已关闭"
7. 更新页面状态，显示"开启 CLS"按钮

**确认对话框**：
- 标题："关闭 CLS 日志服务"
- 内容："确定要关闭 CLS 日志服务吗？关闭后将无法收集系统日志。"
- 按钮："取消"、"确认"

### 页面交互流程

1. **初始加载**：
   - 加载今天的数据
   - 显示全局配额消耗
   - 显示最近 7 天的趋势图
   - 加载会话列表（第一页）

2. **日期范围选择**：
   - 用户选择日期范围
   - 刷新所有数据和图表
   - 加载新的会话列表

3. **标签页切换**：
   - 用户点击"按用户"或"按模型"标签页
   - 加载对应的数据
   - 显示对应的表格

4. **会话下钻**：
   - 用户点击会话列表中的会话名称
   - 跳转到会话详情页面
   - 显示会话的完整对话历史

5. **手动刷新**：
   - 用户点击刷新按钮
   - 显示加载状态
   - 重新加载所有数据

### 核心图表和数据展示

#### 1. 日志级别分布（柱状图）

展示不同日志级别（ERROR、WARNING、INFO、DEBUG）的日志数量分布。

**数据源**：API: `GET /api/logs/level-distribution`

**交互**：
- 支持鼠标悬停查看具体数值
- 支持点击柱子筛选该级别的日志

#### 2. 日志模块分布（水平柱状图）

展示不同模块的日志数量分布，帮助快速定位问题所在的模块。

**数据源**：API: `GET /api/logs/module-distribution`

**交互**：
- 支持鼠标悬停查看具体数值
- 支持点击柱子筛选该模块的日志
- 支持点击模块名称查看该模块的详细日志

#### 3. 消息处理统计（折线图）

展示消息处理数量和队列中的消息数量随时间的变化。

**数据线**：
- 已处理消息数（绿色）
- 队列中的消息数（蓝色）

**数据源**：API: `GET /api/messages/processing-stats`

**交互**：
- 支持鼠标悬停查看具体数值
- 支持点击图例切换显示/隐藏对应的数据线

#### 4. 队列状态监控（折线图）

展示队列的平均深度和平均等待时间随时间的变化。

**数据线**：
- 队列平均深度（蓝色）
- 平均等待时间（毫秒，紫色）

**数据源**：API: `GET /api/queue/status`

**交互**：
- 支持鼠标悬停查看具体数值
- 支持点击图例切换显示/隐藏对应的数据线

#### 5. 日志搜索和筛选

支持多维度的日志搜索和筛选。

**筛选条件**：
- 日志级别（ERROR、WARNING、INFO、DEBUG）
- 模块（下拉列表，从日志数据中提取）
- 关键词搜索（模糊匹配日志内容）
- 日期范围

**交互**：
- 用户选择筛选条件
- 点击"搜索"按钮
- 显示加载状态
- 加载符合条件的日志列表

#### 6. 日志列表

展示符合筛选条件的日志详情。

**表格列**：

| 列名 | 说明 | 数据来源 |
|------|------|--------|
| 时间 | 日志的时间戳 | API: `GET /api/logs/search` |
| 级别 | 日志级别（ERROR、WARNING 等） | API: `GET /api/logs/search` |
| 模块 | 日志所属的模块 | API: `GET /api/logs/search` |
| 消息 | 日志内容 | API: `GET /api/logs/search` |

**交互**：
- 支持分页显示（每页 10/20/50 条）
- 支持点击日志查看完整内容

   - 加载对应页的数据

5. **会话下钻**：
   - 用户点击会话列表中的会话名称
   - 跳转到会话详情页面
   - 显示会话的完整对话历史

6. **手动刷新**：
   - 用户点击刷新按钮
   - 显示加载状态
   - 重新加载所有数据

## CLS 日志服务统一规范

### 功能说明

CLS（Cloud Log Service）日志服务是一个可选的系统日志收集和分析服务。管理员可以在三个核心页面中随时开启或关闭该服务。

### 开启流程（统一）

1. 用户点击页面右上角的"CLS"按钮
2. 系统调用 API: `POST /api/cls/enable`
3. 显示加载状态（可选的加载动画或进度条）
4. 成功后显示 Toast 提示

**Toast 提示**：
- 类型：成功（Success）
- 标题：无
- 内容："CLS 日志服务已开启"
- 图标：绿色对勾
- 背景色：绿色（#10b981）
- 文字颜色：白色
- 持续时间：3 秒自动关闭
- 位置：右下角

### 关闭流程（统一）

1. 用户点击页面右上角的"关闭 CLS"按钮
2. 显示确认对话框
3. 用户点击"确认"按钮
4. 系统调用 API: `POST /api/cls/disable`
5. 显示加载状态
6. 成功后显示 Toast 提示

**确认对话框**：
- 标题："关闭 CLS 日志服务"
- 内容："确定要关闭 CLS 日志服务吗？关闭后将无法收集系统日志。"
- 按钮："取消"、"确认"
- 默认焦点：取消按钮

**Toast 提示**：
- 类型：成功（Success）
- 标题：无
- 内容："CLS 日志服务已关闭"
- 图标：绿色对勾
- 背景色：绿色（#10b981）
- 文字颜色：白色
- 持续时间：3 秒自动关闭
- 位置：右下角

### 错误处理

如果 API 调用失败，显示错误 Toast 提示：
- 类型：错误（Error）
- 内容："操作失败，请稍后重试"
- 图标：红色叉号
- 背景色：红色（#ef4444）
- 文字颜色：白色
- 持续时间：5 秒自动关闭
