# Spacing

## 1. 页面级节奏

| Scope | Recommendation |
|---|---|
| Admin 主内容区 | `p-8` |
| 标题区到底部主内容 | `mb-6` 或 `mb-8` |
| 筛选区控件间距 | `gap-3` |

## 2. 卡片与模块

| Scope | Recommendation |
|---|---|
| 普通 Admin 卡片内边距 | `p-5` 或 `p-6` |
| 表格单元格横向间距 | `px-4` 到 `px-6` |
| Dialog 内容区 | `space-y-4` 或 `space-y-6` |
| TenantCard 默认 | `padding 20px` + `gap 24px` |

## 3. 使用原则

- 优先保持同一页面的节奏一致，不要局部临时发明 spacing。
- 宿主仓换皮时，如果组件 API 不同，也要先对齐模块间距，再去修微观像素。
