SKILL.md

Portable Design Skill

统一 ClawPro 设计资产的可移植版本，支持跨仓 fallback 与离线 HTML 预览。

核心能力

  • 组件 spec：每个组件对应一份 component-specs/*.md
  • Portable 模板：HTML/CSS 与 React 双轨产物，跨仓直接可用
  • Tokens：通过 portable/css/tokens.css 暴露设计变量

使用约定

  • 新增页面前查阅 SKILL.md 决策表
  • 组件命中已有 spec 时禁止再手写实现

非 Markdown 文件：自动切到 Source 模式

选中 .ts / .json / .yaml 等非 markdown 文件时，viewMode 自动切到 Source；用 <pre> 等宽字体 + 软换行渲染，背景 --cp-bg-subtle。
