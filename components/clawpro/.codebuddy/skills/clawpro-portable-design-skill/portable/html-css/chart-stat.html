规则

• 主数字使用稳定的 tabular nums，避免统计卡位移

• 主趋势色统一品牌蓝，辅助线和网格使用弱灰

• Tooltip 白底、4px 圆角、overlay shadow，不直接漂浮裸字

• 空态、加载态、错误态、无权限态都必须完整
