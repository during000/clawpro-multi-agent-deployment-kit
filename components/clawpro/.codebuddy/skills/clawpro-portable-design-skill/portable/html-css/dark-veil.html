DarkVeil（L1 静态兜底）

根据 `component-specs/dark-veil.md §9.2` 生成的 L1 静态 CSS 兜底，零 WebGL、零依赖， 模拟 demo 仓 `DarkVeil.tsx`（L0 完整移植）的「白底 + 蓝紫飘带」hero 观感。

hero 三层配方（基底 + 径向光晕飘带 + 收束叠层）

开通云开发能力

示例 hero 区文案。DarkVeil 仅作装饰背景，文字 / 按钮始终落在 z-10 内容层之上。

规则

• 纯背景组件：背景层全部 pointer-events:none，不承载信息 / 交互 / 可点击元素

• 仅用于命中 Auto-Trigger 的管控端开通页 / 能力 hero，禁止扩散到列表 / 表单 / 整页背景

• 三档兜底：L0 完整移植（ogl + WebGL）→ L1 本文件静态 CSS（默认档）→ L2 纯色 / 截图

• 配色常量：基底 `--cp-darkveil-base` #E0EBFE、飘带 `--cp-darkveil-tint` #B2C3FF，顶部 mask 22% 淡出露基底

• 已尊重 `prefers-reduced-motion`：偏好减少动效时停止流动动画
