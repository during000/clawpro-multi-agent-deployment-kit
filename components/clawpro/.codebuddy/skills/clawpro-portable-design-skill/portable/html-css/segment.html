✅ 推荐做法

• Admin 和 Tenant 端别需在路由层提前确定，不要在组件内部自己判断

• 项数 ≤ 5；超过 5 项改用侧导航或分页（不要硬塞）

• Active 项必须同时有背景 + 阴影，不仅靠颜色微差

• 卡片分区用受控模式（Segment + SegmentItem + value）

• 筛选条用非受控模式（SegmentGroup + SegmentOption + active）

• 不要在 page header 下方用 Segment（那是 LineTabs 的位置）

❌ 禁止做法

• 混用 Admin 和 Tenant 皮肤（分别用独立组件，不共用）

• 用 className 临时改圆角或颜色（破坏单一真理源）

• 在组件内部自己判断端别（pathname.startsWith 等）

• 项数 > 5 时硬塞到 Segment（应改用侧导航结构）
