Toast - 操作反馈通知

✓ Success
toast.success("操作成功")
✗ Error
toast.error("操作失败")
⚠ Warning
toast.warning("警告提示")
ⓘ Info
toast.info("信息提示")
长文本
toast.error("长文本...")
自定义时长
toast.success("...", {duration: 2000})

设计规范： 白色背景 (#FFFFFF) + 蓝灰边框 (#EAEEF4) • 圆角 12px • 内边距 12px 16px • 4秒自动消失 • 关闭按钮右上角外侧 • Z-Index 99999
