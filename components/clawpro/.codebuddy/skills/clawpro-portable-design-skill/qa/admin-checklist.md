# Admin Checklist

## 1. 页面骨架

- [ ] 如果交付的是 Admin 完整页面，已包含 `AdminSidebar` / `AdminSidebarInset`，而不是只有局部组件区
- [ ] 页面背景继承管理端主内容区，不手写大面积纯白覆盖
- [ ] 页头包含标题、说明、主操作，结构清楚
- [ ] 筛选区、数据区、反馈区顺序清楚

## 2. 视觉规范

- [ ] 主色使用 `#1447E6` / `#020617` 体系
- [ ] 主品牌色统一使用 Brand Blue / Brand Black 体系
- [ ] 卡片使用正确 Surface 层级
- [ ] 未新增与 Surface 层级冲突的重阴影写法
- [ ] 业务卡片与控件保持 4px 基线，不误用 Tenant 12px 卡片

## 3. 组件使用

- [ ] 主按钮优先 `claw-primary`
- [ ] 次级按钮优先 `claw-outline`
- [ ] 表格按 Table spec 使用
- [ ] 表格仅承载表格本身；标题、描述、刷新/创建等操作按钮已放到表格外
- [ ] 危险操作有二次确认
- [ ] 空态、加载态、错误态完整

## 4. 迁移与兼容

- [ ] 如果宿主仓未直接使用 demo 组件，也已按 portable fallback 还原
- [ ] 未把 demo 仓组件名当成唯一实现方式
- [ ] 旧页面触达区域至少减少了旧写法，而不是继续增加

## 5. 交付检查

- [ ] 页面说明了依赖的 spec
- [ ] 如有冲突，已记录到 `references/conflict-log.md`
- [ ] QA 能在不读源码的前提下理解目标视觉
