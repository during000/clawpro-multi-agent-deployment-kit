# Tenant Checklist

## 1. 页面骨架

- [ ] 页面属于 Tenant 范围时，已按 Tenant 差异规则执行
- [ ] 背景、顶部导航、内容骨架符合 Tenant 口径
- [ ] 页面主区块层级清楚，没有混入 Admin 风格卡片

## 2. 视觉规范

- [ ] Tenant 业务卡片使用 12px 口径或等效 fallback
- [ ] Tenant 主次按钮使用 `tenant-*` 视觉
- [ ] 没有把 Admin 4px 业务卡片机械搬进 Tenant 页面
- [ ] 没有恢复已废弃的旧装饰背景或旧品牌色

## 3. 组件使用

- [ ] 高风险组件已按对应 portable spec 实现
- [ ] 文字层级尽量映射到 Typography 语义
- [ ] 空态分清页面级和容器级，不滥用大插画
- [ ] 表单控件和筛选条不自行发明新形态

## 4. 迁移与兼容

- [ ] 如果宿主仓不能直接用 demo 组件，已参考 fallback 实现
- [ ] 历史页面触达区域没有继续新增旧写法
- [ ] 共享组件与 Tenant 差异的边界清楚

## 5. 交付检查

- [ ] 页面说明了所依据的 spec
- [ ] 必要时补充了宿主仓映射说明
- [ ] 设计、前端、AI 都能从文档直接理解目标结果
