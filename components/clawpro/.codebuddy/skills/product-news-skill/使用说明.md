# Product News Skill 使用说明

## 这个 skill 用来做什么

`product-news` 用于在 PM 本地开发完成后、提 MR 之前，综合聚合多源上下文（CodeBuddy 会话上下文 + git diff + TAPD 需求单）生成产品动态文案并写入 `product-news.yml`。

它解决的问题是：功能上线后，需要面向外部用户发布标准化的产品动态文案，而不是靠人记得去平台手动录入。v3 进一步把生成时机前置到 PM 本地 CodeBuddy 环境，一次审核后随 MR 提交。

## 适用场景

- Demo 或产品功能本地开发完成，准备提 MR 之前。
- 需要生成符合腾讯云官网规范的产品动态标题和描述。
- 需要把产品动态文案随 MR 一起提交到仓库，供 AutoSync Bot 自动抓取录入云端并发布。
- 推荐时机：在多人协作分支开发手册的「步骤 6 rebase main 解决冲突」之后、「步骤 7 push 发起 MR」之前调用本 skill。

## v3 新增能力（相比 v2）

| 能力 | v2 | v3 |
|---|---|---|
| 上下文来源 | 仅 git diff + MR 信息 | 多源上下文（CodeBuddy 会话 + git diff + TAPD MCP） |
| 审核环节 | CodeBuddy 内审核 | CodeBuddy 内审核（不变） |
| Operation Guide | skill 内置调用 | **引导** PM 调用已安装的 `@clawpro-operation-guide`（不打包对方代码） |
| 高风险类提示 | 无 | type=功能上线 且涉及合规/隐私/计费/配额/权限时提示 PM 考虑 `auto_publish=false` |
| auto_publish 默认值 | false | **true**（CodeBuddy 已审核，默认自动发布） |
| source 字段 | 仅 `mr_id` | 新增 `frontend_mr_id`（区分前后端 MR） |
| update-awareness 集成 | 不涉及 | v3 暂不集成（related_campaign 字段保留） |
| 仓库地址 | 不涉及 | skill 内不硬编码（由 Bot 配置维护） |

## 核心工作流程（v3：9 步）

1. **步骤 0：聚合多源上下文**
   - 0.1 读取 git diff（变更文件、关键 diff 摘要）
   - 0.2 LLM 自然利用 CodeBuddy 会话上下文（无需 PM 手动总结）
   - 0.3 PM 提供 TAPD 链接 → skill 调 TAPD MCP 现场拉取需求单内容（可选）
2. **步骤 1：LLM 生成文案**（综合多源上下文，一次生成终稿，并判断管控端或用户端）
3. **步骤 2：PM 在 CodeBuddy 内审核**（展示文案预览、端类型以及 Banner/浮窗开启建议与理由，再由 PM 最终确认）
4. **步骤 3：Operation Guide 引导调用**（PM 回答"是"时，引导 PM 调用 `@clawpro-operation-guide`，**不打包对方代码**）
5. **步骤 4：高风险类提示**（type=功能上线 且涉及合规/隐私/计费/配额/权限时，提示 PM 考虑 `auto_publish=false`）
6. **步骤 5：生成 id**（`{type-prefix}-{slug}-{date}` 格式）
7. **步骤 6：构造完整条目**（auto_publish 默认 true；source 新增 frontend_mr_id）
8. **步骤 7：写入 `.clawpro/product-news.yml`**（按 id 去重，增量追加）
9. **步骤 8：校验 YAML 格式合法性**

## 两个产物

| 产物 | 路径 | 用途 |
|---|---|---|
| 产品动态文案 | `.clawpro/product-news.yml`（仓库内） | 随 MR 提交，AutoSync Bot 抓取录入云端并发布 |
| 官网操作指南 | `~/.clawpro/product-news-guides/{change_id}/`（本地） | 由 `@clawpro-operation-guide` 生成，**不上传 MR**，可手动上传到写写平台 |

## 如何调用

### 最短调用

```
@product-news 帮我生成本次变更的产品动态
```

### 推荐：提供 TAPD 链接作为补充上下文

```
@product-news 生成本次的产品动态。
TAPD 需求单：https://www.tapd.cn/20422209/prong/stories/view/1020422209135360254
```

### 完整上下文调用（推荐）

```
@product-news 生成本次的产品动态。
功能说明：新增了 Agent 计费模式配置页面，支持按量计费和包年包月切换。
TAPD 需求单：1020422209135360254
前端 MR：!1234
```

### 查看已有产品动态

```
@product-news 显示当前已有的产品动态列表
```

## 输出内容

标准输出包含：

- 文案预览表格（title / type / date / version / description）
- 端类型（endpoint：管控端 / 用户端）
- 展示组件建议（Banner / 浮窗分别给出建议与理由，并预填到 YAML 草案，由 PM 最终确认或修改）
- 展示组件配置（按推荐值预填；开启且未指定时长时默认存在14天；PM 未确认前不可提交）
- Duration 确认（仅对已开启的 Banner/浮窗展示默认14天并要求 PM 确认或分别修改；全部关闭时跳过）
- Banner 和浮窗均展示给管控端管理员；即使 `endpoint=用户端`，只要涉及管理员的管理、答疑、权限、安全、成本、推广或用户行为变化，也会给出开启建议
- 推荐值可先写入 `.clawpro/product-news.yml` 草案；PM 未确认前不得作为可提交产物，修改组件开关或时长后按同一 id 更新
- 高风险类提示（如有，提示 PM 考虑 `auto_publish=false`）
- 写入的文件路径和变更摘要
- 格式校验结果（通过 / 失败 + 具体问题）
- 下一步提示

## 文案质量保障

skill 内嵌腾讯云官网文档写作规范，生成的文案自动满足：

- 标题：名词性词组，≤80 字，无 emoji，不以动词开头
- 描述：面向用户，≤2000 字，句号结尾
- 空格：中英文间、数字与单位间、取值范围
- 用词：您、账号、例如、无口语化
- 产品名：ClawPro / OpenClaw 严格区分

详见 `references/copy-guidelines.md`。

## 多源上下文说明（v3 新增）

### CodeBuddy 会话上下文

LLM 在生成文案时**自然利用**当前会话的开发讨论上下文，包括 PM 描述的功能需求、影响范围、用户价值等。无需 PM 手动总结。

### TAPD 需求单内容

PM 提供 TAPD 单链接/ID 后，skill 通过 TAPD MCP（`mcpgw.knot.woa.com/tapd/`）现场拉取需求单标题、描述、验收标准等内容，填入 Prompt 作为补充上下文。

**降级策略**：TAPD MCP 不可用时（网络问题、token 缺失等），skill 提示 PM 手动粘贴 TAPD 需求单的关键内容，不阻塞流程。

### git diff

skill 执行 git 命令获取本次代码变更，自动排除 lock 文件、配置文件等噪音。

## 降级策略

- **LLM 不可用**：skill 使用确定性规则生成占位文案，并明文标注「⚠️ 需人工润色」
- **TAPD MCP 不可用**：skill 提示 PM 手动粘贴 TAPD 需求单内容
- **高风险类提示不可用**（LLM 降级时）：skill 提示 PM 自行评估本次变更是否涉及合规/隐私/计费/配额/权限类调整
