# 产品动态官网文案规范

> 来源：AutoSync 项目 `backend/app/services/reviewer.py` 中的 `AI_REVIEW_PROMPT`，腾讯云官网文档写作规范。
>
> **skill 在生成文案时必须内嵌本规范，一次生成即符合官网标准。**

---

## 一、标题规范

| # | 规则 | 正例 | 反例 |
|---|---|---|---|
| T1 | **名词性词组结构**（不以动词开头） | `用户管理支持分组功能` | `支持用户管理分组功能` |
| T2 | 结构为「主语 + 动词 + 宾语」 | `模型配置新增高级参数` | `新增高级参数配置` |
| T3 | 禁止以「支持」「新增」等动词开头 | `Agent 支持多种模型` | `支持 Agent 接入多种模型` |
| T4 | 标题末尾不加句号 | `功能上线标题` | `功能上线标题。` |
| T5 | 禁止用 `&` 表示并列，用「和」或「与」 | `创建和删除` | `创建&删除` |
| T6 | 禁止用 `/` 表示并列，用「与」或「或」 | `启用与停用` | `启用/停用` |
| T7 | 标题简洁，建议 ≤ 30 字 | — | — |
| T8 | 禁止 emoji | — | — |

### 标题改写示例

```
❌ 支持用户管理分组功能
✅ 用户管理支持分组功能

❌ 新增支持小米 Mimo 模型
✅ 模型配置新增小米 Mimo 模型

❌ 支持 Hermes 模型、通道和 Skill 一键配置功能
✅ Hermes 模型、通道和 Skill 支持一键配置

❌ 支持打开 OpenClaw 内的云端浏览器
✅ OpenClaw 支持打开云端浏览器
```

## 二、描述规范

| # | 规则 |
|---|---|
| D1 | 描述末尾必须加句号「。」 |
| D2 | 交代功能名称、变更内容、影响范围 |
| D3 | 面向用户阅读，去掉技术实现细节 |
| D4 | 长度 1-2000 字符 |

---

## 三、空格规范

| # | 规则 | 正例 | 反例 |
|---|---|---|---|
| S1 | 汉字与英文之间必须有空格 | `云服务器 CVM 为您` | `云服务器CVM为您` |
| S2 | 英文单词之间必须有空格 | `Cloud Virtual Machine` | `CloudVirtualMachine` |
| S3 | 英文单位与汉字之间无需空格 | `单位为Mbps` | `单位为 Mbps` |
| S4 | 数字与汉字之间无需空格 | `支持10个实例` | `支持 10 个实例` |
| S5 | 数字与单位之间无需空格 | `5KB`、`3秒` | `5 KB`、`3 秒` |
| S6 | 取值范围短横线前后加空格 | `10Mbps - 100Mbps` | `10Mbps-100Mbps` |

---

## 四、用词规范

| # | 规则 | 正例 | 反例 |
|---|---|---|---|
| W1 | 称呼用户用「您」 | `您可以...` | `你可以...` |
| W2 | 用「账号」非「帐号」 | `创建账号` | `创建帐号` |
| W3 | 用「账户」非「帐户」 | `账户余额` | `帐户余额` |
| W4 | 举例用「例如」非「比如」 | `例如` | `比如` |
| W5 | 避免口语化表述 | `配置完成` | `搞定`、`就可以了`、`挂掉` |
| W6 | 避免程度副词 | `优化了性能` | `非常优化了性能` |
| W7 | 避免负面情绪词 | `终止`、`移除` | `杀死`、`踢出` |
| W8 | 全文用词保持一致 | — | 不能混用「电脑」和「本地 PC」 |

---

## 五、产品名统一

### ClawPro 项目特殊规则（严格）

| # | 规则 |
|---|---|
| P1 | `ClawPro` 和 `OpenClaw` 是两个不同的产品名，**严禁互相替换** |
| P2 | `管控端` / `用户端` 保持原样，不要改为「管控台」或「控制台」 |

### 需要替换的错误表述

| 错误 | 正确 |
|---|---|
| `龙虾` / `虾` | `OpenClaw` |
| `存量虾` | `存量 OpenClaw` |
| `养虾` | `管理 OpenClaw` / `OpenClaw 运维` |
| `创建龙虾后` | `创建 OpenClaw 后` |

## 六、标点规范

| # | 规则 |
|---|---|
| M1 | 时间用半角冒号：`18:00` 非 `18：00` |
| M2 | 键盘快捷键 `+` 前后不留空格：`Ctrl+C` |
| M3 | 描述末尾必须加句号「。」|

---

## 七、数字用法

| # | 规则 | 正例 | 反例 |
|---|---|---|---|
| N1 | 百分比无空格 | `1%`、`抽样率为5%` | `1 %` |
| N2 | 日期格式 `YYYY-MM-DD` | `2026-07-05` | `2026/07/05` |

---

## 八、书名号处理

- 描述中的「xxx」书名号统一**去掉**，保留 xxx 内容
- 示例：`「模型配置」页面` → `模型配置页面`

---

## 九、质量检查清单

skill 生成文案后，应自检以下条目：

- [ ] 标题是名词性词组（不以动词开头）
- [ ] 标题末尾无句号
- [ ] 标题 ≤ 80 字
- [ ] 描述末尾有句号
- [ ] 汉字与英文间有空格（如 `ClawPro` 前后）
- [ ] 全文无口语化表述（搞定、就可以了）
- [ ] 全文无程度副词（非常、大量、完全）
- [ ] 无「龙虾」「虾」等错误产品名
- [ ] 日期格式正确（YYYY-MM-DD）
- [ ] 无 emoji
