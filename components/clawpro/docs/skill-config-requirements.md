# 技能配置页需求文档

**文档版本**：v1.0  
**创建日期**：2026-03-25  
**所属模块**：管控端 > 技能配置

---

## 概述

技能配置页分为三个独立 Tab，分别负责不同层次的技能管理职能：

| Tab | 名称 | 核心职能 |
|-----|------|----------|
| Tab 1 | 初始技能包 | 配置每个新建 OpenClaw 实例自动预装的技能集合 |
| Tab 2 | 技能安装来源 | 控制用户在 OpenClaw 配置页中可从哪些来源安装新技能 |
| Tab 3 | 私有技能库 | 上传和管理企业内部私有技能，供前两个 Tab 引用 |

---

## Tab 1：初始技能包

### 功能描述

管理员从公开市场或私有技能库中挑选技能，组成一个「初始技能包」。每个新建的 OpenClaw 实例将在初始化时自动预装该技能包中的所有技能。管理员可随时对技能包进行增删，并批量下发至所有现有 OpenClaw 实例。

### 页面副标题

> 每个新建的 OpenClaw 实例将自动预装以下技能

### 页面布局

左右分栏布局：左侧为技能选择区，右侧为当前技能包。

---

#### 左侧 — 技能选择区

包含两个子 Tab：

**子 Tab A：公开市场**

- 展示来自腾讯云 SkillHub 和 ClaWHub 公共技能库的可用技能
- 每个技能以卡片形式展示，包含：技能名称、简介、来源标签（腾讯云 SkillHub / ClaWHub）
- 每张卡片右侧有「+ 加入技能包」按钮；已加入的技能按钮变为「已添加」并置灰

**子 Tab B：私有技能库**

- 展示企业已上传的私有技能列表，卡片形式与公开市场一致
- 每张卡片右侧有「+ 加入技能包」按钮；已加入的技能按钮变为「已添加」并置灰
- **空状态**：「私有技能库暂无技能，[前往私有技能库上传]」（链接跳转至 Tab 3）

---

#### 右侧 — 当前技能包

- 标题：「当前技能包（N 个技能）」
- 列表展示已选技能，每项显示：技能名称、来源标签（公开 / 私有）、右侧删除按钮
- **空状态**：「暂未添加技能，新建 OpenClaw 将不包含任何预装技能」
- **底部操作**：
  - 「保存技能包」按钮（主操作）
  - 「批量下发至所有 OpenClaw」按钮（次操作，点击后弹出确认弹窗）

**批量下发确认弹窗**：

> **确认批量下发？**
>
> 此操作将把当前技能包配置覆盖下发至所有现有 OpenClaw 实例，包括已在运行中的实例。请确认后操作。
>
> [取消] [确认下发]

---

## Tab 2：技能安装来源

### 功能描述

管理员通过开关控制用户端 OpenClaw 配置页中可见的技能安装来源。关闭某个来源后，用户将无法从该来源浏览和安装技能。

### 页面副标题

> 控制用户在 OpenClaw 配置页中可以从哪些来源安装新技能

### 页面布局

卡片列表，每个来源一张卡片，自上而下排列。

---

#### 来源卡片列表

| 来源名称 | 说明 | 操作 |
|----------|------|------|
| 腾讯云 SkillHub | 腾讯云官方技能市场 | 启用/禁用开关 |
| ClaWHub 公共市场 | ClaWHub 平台公共技能库 | 启用/禁用开关 |
| 企业 SkillHub | 企业自建技能仓库，用户可从该地址浏览和安装技能 | 启用/禁用开关 + 地址输入框 |
| 私有技能库 | 允许用户从企业私有技能库中安装技能 | 启用/禁用开关 |

**卡片结构**：

每张卡片包含：
- 来源名称（加粗）
- 一行说明文字（灰色）
- 右侧启用/禁用开关
- 需要填写地址的来源（企业 SkillHub），开关开启后展开地址输入框

**特殊状态**：

- 「私有技能库」来源：若 Tab 3 中尚未上传任何技能，开关置灰并显示提示「私有技能库暂无技能，[前往上传]」

**底部操作**：「保存配置」按钮

---

## Tab 3：私有技能库

### 功能描述

企业专用的私有技能管理区域。管理员在此上传企业内部开发的技能压缩包，上传后的技能可被 Tab 1（初始技能包）和 Tab 2（技能安装来源）引用。

### 页面副标题

> 上传和管理企业内部的私有技能，可用于初始技能包和用户端技能安装

### 页面布局

顶部操作栏 + 技能列表。

---

#### 顶部操作栏

- 「上传技能包」按钮（主操作，蓝色）
- 搜索框（技能较多时使用）

**上传弹窗**：

点击「上传技能包」后弹出上传弹窗，包含：
- 文件上传区域（支持拖拽，接受 `.zip` 格式）
- 技能名称输入框（必填）
- 技能描述输入框（选填）
- [取消] [确认上传] 按钮

---

#### 技能列表

每行显示：

| 字段 | 说明 |
|------|------|
| 技能名称 | 上传时填写的名称 |
| 版本号 | 从压缩包中读取，或上传时手动填写 |
| 上传时间 | 格式：YYYY-MM-DD HH:mm |
| 状态标签 | 「已在技能包中」（蓝色）/ 「未使用」（灰色） |
| 操作 | 「查看详情」「删除」 |

**空状态**：「暂无私有技能，点击「上传技能包」开始上传」

**删除确认**：删除技能时，若该技能已被加入初始技能包或已开放给用户安装，弹出警告提示，说明影响范围后二次确认。

---

## 跨 Tab 联动规则

1. **Tab 3 → Tab 1**：在 Tab 3 上传技能后，Tab 1「私有技能库」子 Tab 中立即可见该技能
2. **Tab 3 → Tab 2**：Tab 3 有技能时，Tab 2「私有技能库」来源的开关自动解锁（不再置灰）
3. **Tab 1 / Tab 2 → Tab 3**：当 Tab 1 或 Tab 2 中私有技能库为空时，显示引导链接跳转至 Tab 3

---

## 名称说明

| Tab 名称 | 设计考量 |
|----------|----------|
| **初始技能包** | 强调「开箱即用」，比「预设技能」更直白，用户能快速理解这是每个实例初始化时自动装好的技能集合 |
| **技能安装来源** | 直接说明用途——控制用户从哪里安装技能，比「技能选择范围」更具体 |
| **私有技能库** | 强调「企业私有」属性，与「公开市场」形成对比，语义清晰 |
