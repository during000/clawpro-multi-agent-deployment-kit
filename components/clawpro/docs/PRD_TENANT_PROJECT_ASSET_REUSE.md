# 用户端复用“资产管理-项目”能力需求单

## 需求概览

| 端 | 分类 | 模块 | 优先级 | 预期时间 |
| --- | --- | --- | --- | --- |
| 用户端 | 能力复用 | 项目协作-资产管理 | P0 | 周五 |

## 一、用户端

### 需求点一：用户端复用管控端“资产管理-项目”能力

#### 1. 改动内容

点击看原图

在用户端“项目协作”中复用管控端“资产管理 → 项目”的现有能力，让用户能够直接在用户端完成项目、成员、项目资产和项目实例管理。

除“上传新资产”外，用户端能力、数据和处理规则与管控端“资产管理 → 项目”保持一致。

#### 2. 项目列表与项目管理

用户可以在用户端查看自己有权限访问的项目。

支持以下能力：

- 搜索项目。
- 刷新项目列表。
- 新建项目，新建时只需填写项目名称。
- 编辑项目名称。
- 删除项目。
- 查看项目成员数量。
- 切换项目后，右侧展示当前项目对应的资产和实例信息。

处理规则：

- 用户只能查看和管理自己有权限访问的项目。
- 用户端与管控端使用同一份项目数据，不创建独立副本。
- 任一端新建、编辑或删除项目后，另一端刷新即可看到最新结果。
- 删除项目时沿用管控端现有的删除确认和校验规则。
- 新建项目默认允许项目创建人维护项目资产，后续可由管理员调整成员编辑权限。

#### 3. 项目成员管理

点击看原图

用户可以查看当前项目的成员，并在具备权限时添加或移除项目成员。

支持以下能力：

- 在项目名称旁查看成员数量，悬浮后查看成员标签列表。
- 通过成员标签列表末尾的“添加”入口，将企业现有用户加入项目。
- 通过成员标签上的移除入口，将成员从项目中移除。

处理规则：

- 添加成员只建立用户与当前项目的关联。
- 成员数量、悬浮列表、添加弹窗和移除确认弹窗与管控端资产管理的项目成员交互保持一致。
- 项目创建人显示“创建人”标识，不提供移除入口。
- 移除成员不删除企业用户账号。
- 成员调整后，用户端和管控端展示相同结果。
- 被移出项目的用户不再拥有该项目的访问权限。

#### 4. 项目资产管理

点击看原图

用户可以在“项目资产”中查看和维护当前项目的资产配置。

支持以下能力：

- 查看当前项目资产版本。
- 查看项目资产更新记录。
- 查看项目同步模式。
- 查看项目已配置的资产数量和资产清单。
- 查看当前项目是“可编辑资产”还是“资产只读”。
- 编辑项目资产配置。
- 从企业已有资产中添加资产。
- 从当前项目中移除资产。
- 保存或取消本次编辑。

资产类型包括：

- 模型配置。
- 公共技能。
- 企业技能。
- 企业插件。
- 企业 MCP。
- 企业规范。

处理规则：

- “项目资产”和“项目实例”使用两个独立 Tab 展示，不在同一页面上下堆叠。
- 管理员可以通过“允许项目成员编辑资产”开关控制成员权限；开关关闭后，项目成员只能查看资产、版本和更新记录，不能添加、移除或保存资产。
- 项目同步模式固定为“所有实例始终同步更新”，用户端仅展示，不允许修改。
- 添加资产时，只能选择企业资产库中已有且当前项目有权使用的资产。
- 添加资产弹窗的分类顺序、搜索、应用范围过滤、版本与范围标签、勾选状态、已选数量和空状态与管控端资产管理保持一致。
- 已加入当前项目的资产保持选中，避免重复添加。
- 移除资产只解除资产与当前项目的关联，不删除企业资产本身，也不影响其他项目。
- 点击“保存”后才正式更新项目资产，并生成新的资产版本和更新记录。
- 点击“取消”时撤销本次尚未保存的修改。
- 保存失败时保留当前编辑内容，提示失败原因并支持重新保存。

#### 5. 不支持上传资产

用户端不提供任何上传或创建企业资产的入口。

具体包括：

- 添加资产弹窗中不展示“上传新资产”。
- 不支持上传企业技能、企业插件、企业 MCP 或企业规范。
- 不支持在用户端新建模型配置或其他企业资产。
- 当企业资产库中没有可选资产时，仅展示空状态，不引导用户上传。
- 用户如需新增企业资产，仍需由管理员在管控端对应资产库中完成。

#### 6. 项目实例

点击看原图

用户可以在“项目实例”中查看当前项目关联的 Agent 实例。

展示内容：

- 实例名称和实例 ID。
- 当前状态。
- 用户 ID。
- 所属项目。
- Agent 类型。

处理规则：

- 项目实例列表仅用于查看，不提供实例编辑或删除操作。
- 同一个实例属于多个项目时，展示完整的项目归属信息。
- 当前项目没有关联实例时，展示明确的空状态。

#### 7. 数据同步与权限规则

- 用户端与管控端复用同一份项目、项目成员、项目资产、资产版本、更新记录和项目实例数据。
- 用户端完成的项目或资产修改，在管控端刷新后可见。
- 管控端完成的修改，在用户端刷新后可见。
- 用户端不因复用该功能扩大项目或企业资产的可见范围。
- 用户只能操作自己有权管理的项目和资产。
- 用户权限在编辑过程中被收回时，不允许继续保存，并提示刷新页面。
- 多人同时编辑时，以平台返回的最新项目资产版本为准；当前版本过期时提示用户刷新后重新确认，不静默覆盖他人修改。

#### 8. 本期不做

- 不支持在用户端上传、创建、编辑、更新、下架或删除企业资产源。
- 不允许修改项目资产同步模式。
- 不新增资产类型。
- 不修改管控端“资产管理 → 项目”的现有业务规则。
- 不新增独立的资产下发、重试或审计链路，继续沿用管控端现有处理流程。

#### 9. 验收标准

- 用户可以在用户端搜索、刷新、新建、编辑和删除自己有权限管理的项目。
- 新建项目时只需填写项目名称。
- 用户可以在项目名称旁查看成员数量，通过悬浮成员列表添加和移除项目成员；创建人不可移除。
- 用户可以查看项目资产版本、更新记录、同步模式、资产数量和资产清单。
- 管理员可以控制是否允许项目成员编辑资产；关闭后成员只读且不显示编辑入口。
- 用户可以从企业已有资产中添加六类项目资产。
- 添加资产弹窗与管控端保持一致，并支持分类切换、搜索、范围标签、勾选和已选数量展示。
- 用户可以从当前项目中移除资产并保存。
- 用户端不展示任何资产上传或资产创建入口。
- 企业资产库为空时只展示空状态，不引导用户上传。
- 项目同步模式固定为“所有实例始终同步更新”，用户不能修改。
- 用户可以查看项目关联的 Agent 实例及其实例名称、ID、状态、用户 ID、所属项目和 Agent 类型。
- “项目资产”和“项目实例”分别作为独立 Tab 展示。
- 用户端与管控端使用同一份项目、成员、资产、版本、更新记录和实例数据。
- 任一端修改后，另一端刷新能够看到最新结果。
- 用户端复用该能力后不会扩大项目或企业资产的访问权限。
- 保存失败、权限变化和版本冲突均有明确提示，不会静默覆盖已有配置。
