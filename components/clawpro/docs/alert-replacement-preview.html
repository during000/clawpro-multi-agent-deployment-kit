Alert 替换前后对比 — UI 走查

将项目中硬编码的蓝色提示条统一替换为 @/components/ui/alert.tsx 的标准 <Alert variant="info">。共 4 个文件 5 处。

变更要点

  • 背景色：#eff6ff（tailwind bg-blue-50）→ #f0f3fc（设计 token --alert-info-bg，更柔和的浅紫蓝）
  • 边框色：#dbeafe（border-blue-100）→ #bfcffe（--alert-info-border，对比度更高）
  • 文字色：#1d4ed8 / #2563eb（彩色文字）→ #0a0a0a（--alert-info-foreground，深色无障碍文本，仅图标保留蓝色 #1447e6）
  • 圆角：随意的 rounded-lg / rounded-[4px] / rounded-xl → 统一 4px（全局 --radius）
  • 图标：ⓘ Unicode 字符 / Info lucide → 统一 <AlertInfoIcon />（lucide Info）
  • 语义：自定义 div → 标准 role="alert"，可访问性内置
