Combobox → Select 全量替换计划

对两个仓库中所有「Combobox」相关用法的可视化盘点与替换方案。每个条目附「界面截图模拟 + 组件引用名 + 替换映射」。

仓库：design-integration-2026 + enterprise-fronted 真实业务调用：13 处 可复用筛选组件：5 个 死代码：1 个（AgentCombobox）
关键前提：项目里没有真正的 <Combobox> 组件被使用。
  • 除了已删除/无引用的 OpenClawCombobox.tsx（导出 AgentCombobox，基于 cmdk Command 实现）外，所有出现的 combobox 都是无障碍属性 role="combobox"，挂在自建 Popover 下拉触发器（<Button> / <button>）上。
  • 这些「伪 Combobox」内部各自手写了树形/分组/搜索/确认逻辑，并非标准 Select 组件。
  • 因此「替换成 Select」的真实含义 = 用统一的 Select / SearchableSelect / TreeSelectFilter 收敛这些重复的自建下拉，并移除散落的 role="combobox" 与死代码。

1

清理死代码（最低风险，先做）

enterprise-fronted/components/OpenClawCombobox.tsx
2

增强收敛目标组件 TreeSelectFilter

为 TreeSelectFilter 增加 sections（分区）、showSearch 开关、triggerVariant（button/filter-icon）三项能力，使其能承接所有单选树/部门/分组筛选场景。

两仓 components/_internal/TreeSelectFilter.tsx
3

替换「单选树」类自建下拉（主体工作）

把 ①②⑤⑥⑨⑩⑪⑫ 共 9 个单选树筛选器全部替换为增强后的 TreeSelectFilter，并合并 ④ GroupSingleFilter。删除各页手写的 TreeNode 组件，移除散落的 role="combobox"。

OpenClawMonitor / TokensMonitor / MemberManagement / FileManagement / DepartmentInfo / GroupSingleFilter
4

保留并对齐「非 Select 语义」组件

③ GroupMultiFilter（多选树）、⑧ ModelCascader（级联）、⑬ CollectScopePopover（范围多选）不替换为 Select，仅统一 trigger 视觉（h-9 / token 描边），并在设计台标注为独立组件族。

GroupMultiFilter / ModelConfig·ModelCascader / CollectScopePopover
