# 需求单：执行命令（Execute Command）

> 版本：v1.0  
> 创建日期：2026-05-14  
> 文档类型：功能需求说明（PRD）  
> 适用范围：管控端 → 运营监控 → Agent 列表 / 执行命令独立页

---

## 1. 背景与目标

### 1.1 背景
管理员日常需要在多台 Agent 实例上执行 Shell 命令完成运维工作（清理日志、重启进程、刷新配置等）。
当前管控端并未提供原生的命令下发能力，相关需求长期借助 TAT（腾讯自动化助手）的"个人命令"功能间接满足，
存在以下问题：

- **命令模板归属于个人，无法在团队内沉淀和复用**：每位运维同学需要重复创建相同命令；
- **审计链条断裂**：命令的创建、修改、下发记录散落在 TAT，无法在管控端统一回溯；
- **工作流割裂**：管理员需要在管控端选实例 → 跳到 TAT 选/创建命令 → 再回到管控端验证结果，体验差；
- **无法做权益隔离**：TAT 的命令是按个人账号区分，多管理员场景下无法共享审计视图。

### 1.2 目标
在管控端原生提供"执行命令"能力，做到：

1. **命令模板由管控端自有数据库存储**，与 TAT 个人命令完全解耦；
2. 管理员可以**勾选实例后直接下发命令**，或**进入命令库挑选模板再选实例**；
3. 提供**测试机优先**机制，降低批量下发风险；
4. 所有下发任务在管控端**统一沉淀执行记录**，包含每台机器的输出与退出码。

### 1.3 范围说明（不在本期范围）
- ❌ 定时执行 / 周期巡检（v1 不做，后续迭代）
- ❌ 分批灰度 / 滚动执行（v1 不做）
- ❌ 命令参数化（v1 命令内容是固定文本，后续考虑 `{{key}}` 变量）
- ❌ 文件分发 / 远程文件传输
- ❌ Playbook（多步组合）
- ❌ 命令权限（角色 / 标签级权限）
- ❌ 命令审批流

## 2. 名词与命名

| 名词 | 含义 |
|---|---|
| **执行命令** | 模块名 / 独立页标题；表示"在 Agent 上执行 Shell 命令"这一能力 |
| **命令模板** | 预先定义、可重复使用的命令配置（含命令内容、超时、执行用户、执行路径等） |
| **下发** | 单次的执行动作，把"命令模板"投递到一组目标 Agent 实例 |
| **执行记录** | 每次下发产生的任务记录，含每台机器的执行结果 |
| **测试机** | 批量下发前，从目标实例中挑出的 1 台先执行的实例，用于验证命令安全性 |

> 按钮文案使用「命令下发」（动作语义清晰，行业惯用语），  
> 模块/页面名使用「执行命令」（容器更宽容，便于未来扩展周期任务、文件分发等子能力）。

## 3. 入口与导航

### 3.1 入口设计原则
**「执行命令」不在侧边栏单独占位**，作为「Agent 列表」的延展能力暴露。
理由：用户的心智路径是"先有要操作的机器，才有命令"，而不是反过来；放在侧边栏会形成两个独立但内容互通的入口，造成困惑。

### 3.2 入口位置

#### 入口 A：Agent 列表 → 工具栏「命令下发」按钮（**主入口**）

按钮在 Agent 列表顶部工具栏，与"批量更新""批量删除"同区域。**根据是否勾选实例呈现两种形态**：

| 状态 | 形态 | 点击行为 |
|---|---|---|
| **未勾选任何实例** | 白底 + dropdown 二级菜单 | 展开下拉，提供 3 个选项 |
| **已勾选 ≥1 台实例** | 蓝色主按钮 + 角标显示数量（如「命令下发 [3]」） | **直接打开**「执行命令」弹窗，预填已勾选实例 |

**未勾选时的下拉菜单内容：**

| 菜单项 | 行为 |
|---|---|
| 立即下发命令 | 打开执行命令弹窗（无预选实例，用户在弹窗内选择命令 + 实例） |
| 命令模板 | 跳转到独立页 `/admin/agent-commands?tab=list` |
| 执行记录 | 跳转到独立页 `/admin/agent-commands?tab=history` |

#### 入口 B：执行记录 toast「查看执行记录」 → 跳到独立页历史 Tab

提交命令后右上角 toast 提供「查看执行记录」按钮，点击直达 `/admin/agent-commands?tab=history`。

#### 入口 C：命令模板 Tab → 单条命令的「下发」按钮（次入口）

进入「执行命令」独立页 →「命令模板」Tab → 任一行右侧「下发」按钮，
打开执行命令弹窗，预填该命令模板（不预填实例，用户在弹窗内挑选）。

### 3.3 独立页路由

| 路径 | 内容 |
|---|---|
| `/admin/agent-commands?tab=list`    | 命令模板 Tab（默认） |
| `/admin/agent-commands?tab=history` | 执行记录 Tab |

页面顶部提供「← 返回 Agent 列表」轻量导航按钮。

## 4. 功能详细说明

### 4.1 命令模板（Command Templates）

#### 4.1.1 数据归属（重要）

**命令模板由管控端独立存储，不依赖 TAT 个人命令。**

- 数据存储在管控端自有数据库中
- 命令属于"租户级共享"：同一租户下的所有管理员可见、可用
- 与 TAT 的关系：**仅在执行阶段调用 TAT 的命令执行通道**（或等效底层能力），命令本身的元数据全部由管控端维护
- 创建命令时**不会**在 TAT 个人命令空间产生任何记录
- 管控端提供独立的命令 ID（如 `cmd-cleanup-logs`），与 TAT 的命令 ID 无关联

#### 4.1.2 命令模板字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 命令名称 | ✅ | ≤60 字节，支持中英文/数字/`_-.` |
| 命令类型 | ✅ | v1 仅支持 `SHELL`（Linux Shell），UI 灰显 |
| 备注 | ❌ | 一段描述文字，便于队友理解用途 |
| 执行路径 | ❌ | 默认 `/root` |
| 执行用户 | ❌ | 默认 `root` |
| 超时时间（秒） | ✅ | 默认 60，范围 1~86400 |
| 命令内容 | ✅ | 多行 Shell 文本 |
| 创建人 | 系统填 | 当前管理员账号 |
| 创建时间 / 更新时间 | 系统填 | |
| 最近执行时间 | 系统维护 | 仅用于列表展示 |
| 总执行次数 | 系统维护 | 仅用于列表展示 |

#### 4.1.3 命令模板列表页

「命令模板」Tab 展示当前租户下所有命令，列：

| 列 | 说明 |
|---|---|
| 命令 ID / 名称 | ID 可一键复制 |
| 类型 | SHELL（暂无其他选择） |
| 命令内容 | 截断展示首行；hover 显示完整内容 |
| 创建人 / 创建时间 | |
| 最近执行 / 总执行次数 | |
| 操作 | 「下发」「编辑」「删除」 |

页面顶部提供：
- 搜索框：支持按命令 ID、名称、内容、创建人模糊匹配
- 「创建命令」按钮（蓝色主按钮）

#### 4.1.4 命令的创建 / 编辑

弹窗形式，字段如 4.1.2 所列。提交前做：

- **命令内容危险检测**：识别 `rm -rf /`、`mkfs`、`dd if=`、`shutdown`、`reboot`、Fork 炸弹等危险模式，触发时给出二次确认
- **名称唯一性校验**：同一租户下命令名称不可重复
- **超时范围校验**：1~86400 秒

#### 4.1.5 命令的删除

二次确认弹窗，文案：「即将删除「{命令名}」，已存在的执行记录不会被删除。」

---

### 4.2 命令下发（Dispatch Flow）

#### 4.2.1 弹窗状态机（重要）

执行命令是**单一弹窗 + 内部多阶段**形式，共 4 个阶段：

```
prepare  →  testing   →  review   →  submitting
 准备态     测试机执行   结果确认    最终下发
                                         ↓
                                       关闭
```

不启用测试机时：`prepare → submitting → 关闭`，跳过中间两阶段。

#### 4.2.2 prepare 阶段（准备）

弹窗内容自上而下：

1. **命令选择 / 预览区**
   - 若打开弹窗时已传入命令模板（来自命令模板 Tab 的「下发」按钮）：直接展示命令名、类型、执行用户、路径、超时、命令内容预览
   - 若未传入命令（来自 Agent 列表勾选实例后打开）：展示**命令搜索框 + 命令列表**，用户搜索并点选一个命令；选完后切换为预览态，右上角提供「切换命令」链接
2. **危险命令告警**（命中危险规则时显示）
   - 红色横幅，列出命中的危险原因
   - 文案末尾："强烈建议先开启「测试机优先」验证后再下发"
3. **执行对象选择**
   - Agent 类型筛选（全部 / OpenClaw / Hermes / LightclawACE / MyAgent）
   - 实例搜索（实例名 / ID / 创建人）
   - 多选表格（仅展示**运行中**的实例），含全选 / 半选状态
   - 已选数量在标题中实时显示
   - **预填规则**：从 Agent 列表勾选实例进入时，预填的实例已被勾选；非运行中的实例自动跳过，并 toast 提示「已自动跳过 N 台非运行中实例」
4. **测试机优先（默认开启）**
   - Checkbox 标题：「测试机优先（推荐）」
   - 描述："先在 1 台测试机上执行，确认输出正常后再下发到剩余实例；过程中你可随时终止。"
   - 勾选时下方展开「从已选实例中选择测试机」下拉框（必选）
   - 不勾选时直接全部下发，无中间确认环节

底部提示文案随状态动态切换：
- 启用测试机 + 多台：「先在 {测试机名} 验证，确认后再下发到剩余 N 台」
- 启用测试机 + 1 台：「仅 1 台实例，将作为测试机执行」
- 不启用测试机：「将立即下发到 N 台实例」

底部按钮：
- 「取消」（次按钮）
- 「在测试机上执行」/「立即下发」（主按钮，文案随测试机开关切换）

主按钮 disable 条件：未选命令 / 未选实例 / 启用测试机但未选测试机。

#### 4.2.3 testing 阶段（测试机执行中）

- 替换 Dialog 内容为居中态：spinner + "正在 {测试机名} 上执行" + "超时 {N} 秒，请勿关闭弹窗"
- **拦截关闭**：点击 X、ESC、点击遮罩均无效，避免用户误操作丢失结果
- 后端实际执行测试机命令；执行完成后进入 review 阶段

#### 4.2.4 review 阶段（结果确认）

展示测试机执行结果，自上而下：

1. **结果横幅**
   - 成功：绿色背景 + ✓ 图标 + 「测试机 {名称} 执行成功」+ 退出码 + 耗时
   - 失败：红色背景 + ✗ 图标 + 「测试机 {名称} 执行失败」+ 退出码 + 耗时
2. **执行结果 (stdout)**：等宽字体显示标准输出，最大高度 160px 可滚动
3. **错误输出 (stderr)**：仅失败时显示，红色背景区分
4. **决策提示横幅**（蓝色背景）
   - 成功："请确认输出无异常。点击「继续下发」会向剩余 N 台实例发送同样的命令。"
   - 失败："测试机执行失败，建议检查命令后重新提交；剩余实例不会被执行。"

底部按钮：
- 「终止下发」（次按钮，始终显示）
  - 点击后 toast：「已终止下发，测试机执行结果已记录，剩余实例未执行」
  - 关闭弹窗
- 「继续下发剩余 N 台」（主按钮，**仅成功 + 多台时显示**）
- 「完成」（成功 + 单台时显示，等同于关闭）
- **失败时不显示主按钮**，只能终止

#### 4.2.5 submitting 阶段

短暂态：用户点击「继续下发剩余 N 台」或「立即下发」后立即触发：

- 后端发起对剩余实例的批量下发
- 弹窗关闭
- 右上角 toast：
  - 标题：「命令已下发到 N 台 Agent」
  - 描述：「测试机验证通过，继续下发到剩余 N-1 台」（启用测试机时）
  - 操作按钮：**「查看执行记录」** → 跳到 `/admin/agent-commands?tab=history`

### 4.3 执行记录（Execution History）

#### 4.3.1 范围
仅包含「执行命令」类型的记录（`action = command-execute`）；
"Agent 升级"等其他类型记录不在本页展示。

#### 4.3.2 列表字段

| 列 | 说明 |
|---|---|
| 任务 ID | 系统生成，可复制 |
| 命令 | 命令名 + 命令内容首行预览；启用测试机时附「测试机优先」标签 |
| 执行人 | 当前操作管理员 |
| 执行时间 | |
| 结果 | ✓ N/N 全部成功 / ⚠ 部分失败（M 失败） / ✗ 全部失败 |

#### 4.3.3 筛选
- 执行人：全部 / 手动 / 自动
- 关键字搜索：任务 ID、命令名、命令内容、执行人

#### 4.3.4 详情弹窗
点击任意记录行打开详情弹窗，展示：

- 任务基本信息（任务 ID / 命令名 / 执行人 / 时间 / 影响 Agent 数）
- 命令快照（完整命令内容、执行用户、路径、超时）
- **测试机结果区块**（仅启用测试机时显示）
  - 测试机名称
  - 测试结果（通过 / 失败）
  - 测试机消息（含 stdout / 退出码 / 耗时）
- **每台实例的执行结果列表**：实例名、状态、退出码、耗时、stdout / stderr 折叠展开

## 5. 数据存储要求

### 5.1 命令模板表
管控端**自有存储**，与 TAT 的命令完全解耦。需支持：

- 按租户隔离
- 软删除（用于审计追溯）
- 索引字段：命令名称、创建人、创建时间

### 5.2 执行记录表
管控端**自有存储**，需支持：

- 单条记录包含：命令快照（命令模板被删除后仍能完整回放）、操作者、所有目标实例、每台实例的 stdout/stderr/exitCode/耗时
- 测试机的执行结果与剩余实例的执行结果分离记录，但归属同一任务 ID
- 按任务 ID、命令 ID、操作者、时间范围检索

### 5.3 与 TAT 的边界
- **命令元数据（模板）**：100% 由管控端存储
- **命令执行（单次任务）**：管控端调用 TAT（或等效底层能力）的执行通道；TAT 返回的结果（stdout/exitCode/耗时）由管控端落库到自己的执行记录中
- 管控端**不**读取 TAT 的"个人命令"列表，**不**在 TAT 创建命令模板

## 6. 交互细节与体验要求

### 6.1 操作流畅性
- 弹窗最大宽度 768px（桌面端常见尺寸），最大高度 88vh，超出滚动
- 命令模板列表页与执行记录列表页支持响应式布局
- testing 阶段超过 2 秒未返回时，spinner 旁追加文案"等待响应中…"

### 6.2 防误操作
- testing / submitting 阶段拦截弹窗关闭
- 危险命令在创建模板时和下发前各告警一次
- 测试机失败时不允许继续下发，必须重新发起

### 6.3 反馈与提示
- 所有成功操作右上角 toast；失败操作以 toast 或弹窗内联提示
- toast 持续时长：成功 4 秒、错误 6 秒（错误需用户更长时间阅读）
- toast 配「查看执行记录」action button，避免用户主动找路径

### 6.4 空态与异常
- 命令模板列表为空：展示空态插画 + 文案"暂无命令，点击「创建命令」开始沉淀团队 SOP"
- 执行记录为空：展示空态文案"暂无执行记录"
- 命令搜索无结果：内联文案"没有匹配的命令；请前往「执行命令」页面创建新命令"
- 选实例时全部非运行中：弹窗内联提示"所选实例中没有运行中的 Agent，无法下发命令"，按钮 disable

---

## 7. 权限与审计

- 任何已登录的管控端管理员均可创建 / 编辑 / 删除命令模板和发起下发（v1 不做细粒度权限）
- 所有操作（命令的增删改、命令的下发）写入管控端的「操作记录」（audit-log）
- 命令删除是**软删除**：执行记录不受影响，详情页仍能完整看到当时的命令快照

---

## 8. 验收标准（DoD）

### 必须项
- [ ] 命令模板由管控端自有数据库存储，与 TAT 个人命令完全独立
- [ ] Agent 列表勾选实例后，「命令下发」按钮变蓝并显示数量；点击直达弹窗，已勾选实例预填
- [ ] 未勾选时，「命令下发」按钮展开二级菜单（立即下发 / 命令模板 / 执行记录）
- [ ] 命令模板可创建、编辑、删除、搜索；危险命令检测生效
- [ ] 测试机优先默认开启；执行流程严格遵循 prepare → testing → review → submitting 状态机
