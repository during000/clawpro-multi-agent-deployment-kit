!
给产品同学的口令
提需求时直接说"claw-primary"或"claw-outline 的 claw-square"，前端就知道你要的样式，不用拉设计反复对图。
更复杂的搭配可以直接复制右侧 token 价签里的代码贴在 PRD 里。
