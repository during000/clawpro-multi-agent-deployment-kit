# 企业技能库 - 安全检测

## 一、功能概述

为企业技能库新增安全检测能力，管理员上传技能时可选择进行安全扫描，由**科恩实验室**和**云鼎实验室**两个引擎对技能文件进行安全分析，检测结果在列表和详情页可视化展示。

---

## 二、功能模块

### 1. 上传/更新时 - 安全检测选项

- 上传/更新技能的对话框顶部（标题下方）展示提示文案：（非本期带来的，仅调整位置）
  - 仅更新企业技能库中的技能版本。
  - 已下发至 Agent 实例的技能不会同步升级，需手动重新下发。
- 新增**「提交安全检测」**勾选项（默认勾选）
- 勾选框旁带安全盾牌图标，标签为「提交安全检测」
- 勾选框下方提示文案：
  > 开启后将由科恩实验室、云鼎实验室对技能文件进行安全分析，包括代码结构、依赖安全、命令执行、网络请求、文件操作、Prompt 注入等维度的全面审查。检测通常在几分钟内完成。
- 勾选后提交，技能进入「安全检测中」状态；未勾选则为「未检测」状态

### 2. 列表页 - 安全状态标识

#### 2.1 安全状态图标

在列表视图（表格/卡片）的**技能名称右侧**显示安全状态小图标，所有状态均显示：

| 状态 | 图标 | 说明 |
|------|------|------|
| 安全检测中 | 蓝色旋转加载图标 | Hover 提示「安全检测中」 |
| 安全 | 绿色盾牌图标 | Hover 提示「安全检测：安全」 |
| 可疑 | 黄色盾牌图标 | Hover 提示「安全检测：可疑」 |
| 恶意 | 红色盾牌图标 | Hover 提示「安全检测：恶意」 |
| 未检测 | 灰色盾牌图标 | Hover 提示「未检测」 |

#### 2.2 手动检测入口

- **表格视图**：操作列「更多」下拉菜单中，当状态为「未检测」时显示「安全检测」选项
- 点击后弹出确认对话框，确认后技能进入「安全检测中」状态，Toast 提示「已提交安全检测，预计 5 分钟后完成」
- 确认框标题：提交安全检测
- 确认框内容：确认对技能「{技能名称}」提交安全检测？检测将由科恩实验室、云鼎实验室进行，通常几分钟内完成。
- 确认按钮：提交检测（品牌渐变色）
- 取消按钮：取消

#### 2.3 判定规则

取两家引擎中**最严重**的结论作为最终状态。例如科恩判定「安全」、云鼎判定「恶意」→ 最终显示「恶意」。

### 3. 详情页 - 安全检测

#### 3.1 顶部安全状态徽章

在技能详情页顶部信息区（版本号旁边）展示安全检测状态徽章：

| 状态 | 徽章样式 | 交互 |
|------|---------|------|
| 安全检测中 | 蓝色底 + 旋转图标 + 「安全检测中」文字 | 无 |
| 安全 | 绿色底 + 盾牌图标 + 「通过安全检测」文字 | 无 |
| 可疑 | 黄色底 + 盾牌图标 + 「存在可疑行为」文字 | 无 |
| 恶意 | 红色底 + 盾牌图标 + 「存在恶意行为」文字 | 无 |
| 未检测 | 灰色底「未检测」+ 蓝色「检测」按钮 | 点击「检测」弹出确认对话框，确认后进入「安全检测中」，Toast 提示「已提交安全检测，预计 5 分钟后完成」 |

#### 3.2 文件列表 Tab - 版本号旁安全图标

在详情页「文件列表」Tab 的**左侧版本列表**中，**最新版本**的版本号左侧展示安全状态小图标：

| 状态 | 图标 | Hover 提示 |
|------|------|-----------|
| 安全检测中 | 蓝色旋转加载图标 | 安全检测中 |
| 安全 | 绿色盾牌 | 安全检测：安全 |
| 可疑 | 黄色盾牌 | 安全检测：可疑 |
| 恶意 | 红色盾牌 | 安全检测：恶意 |
| 未检测 | 灰色盾牌 | 未检测 |

仅最新版本显示安全状态图标，历史版本不显示。

#### 3.3 安全检测报告卡片（可展开/收起）

当安全状态为安全/可疑/恶意时，在详情页顶部信息区下方展示安全检测报告卡片。

- 默认收起，点击展开
- 收起时显示：安全图标 + 「安全检测」标题 + 状态徽章（安全/可疑/恶意）+ 展开箭头

**展开后内容：**

**a) 分引擎检测结果**

两栏卡片并排展示：

| 引擎名称 | 状态指示（圆点 + 文字） | 查看报告链接 |
|----------|----------------------|------------|
| 科恩实验室 | ● 安全，无风险 / ● 存在可疑行为 / ● 存在恶意行为 | 查看报告 ↗（外链新窗口） |
| 云鼎实验室 | ● 安全，无风险 / ● 存在可疑行为 / ● 存在恶意行为 | 查看报告 ↗（外链新窗口） |

- 科恩报告链接格式：`https://tix.qq.com/search/skill?keyword={contentHash}`
- 云鼎报告链接格式：`https://static.cloudsec.tencent.com/html-reports/{date}/{reportId}_{contentHash}.html`

**b) 底部免责声明**

> 安全检测结果由第三方机构出具，仅供参考，不构成平台对 Skill 绝对安全的承诺。网络安全具有动态性，请您自行做好安全防护和风险管控。

### 4. 安全检测状态定义

| 状态 | 英文标识 | 说明 |
|------|---------|------|
| 未检测 | not_scanned | 上传时未勾选安全检测 |
| 安全检测中 | scanning | 已提交检测，等待结果 |
| 安全 | safe | 两家引擎均判定安全 |
| 可疑 | suspicious | 存在可疑行为，最高级别为可疑 |
| 恶意 | malicious | 存在恶意行为 |
