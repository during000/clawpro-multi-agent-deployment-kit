十、组件收敛与一致性优化建议

P0 · 必须收敛 高优先级

  • 合并 ColumnFilters → TableHeaderTreeFilter：DepartmentColumnFilter 与 GroupColumnFilter 与 TableHeaderTreeFilter 视觉/交互几乎一致，应让后者支持sources分桶配置（可选 source labels），统一替换。
  • 替换 AgentCombobox → SearchableSelect：能力重叠，且选中色硬编码偏离规范；除非确需 cmdk 命令式行为，否则迁移到 SearchableSelect。
  • 消灭硬编码选中色：GroupSelectPanel 内 bg-[#EFF4FF]、AgentCombobox bg-blue-50 → 统一改为 bg-[var(--bg-brand-selected)]。

P1 · 视觉一致性 中优先级

  • 选项行规范统一：所有面板选项行统一为 h-8 px-3 rounded-[6px]，禁止再用 py-1.5 px-2.5 rounded-[4px] 这类变体（GroupSelectPanel / ScopeEditPopover 内部）。
  • 选中态文字色：选中态的文字颜色统一 text-blue-500 + font-medium（参考 TableHeaderTreeFilter / Select），ScopeEditPopover、GroupSelectPanel 当前只有背景高亮无字色。
  • 触发器 hover 描边色统一：TokenValueEditor 用 #1447E6，其它统一 blue-500，应改为 blue-500 与 Select 一致。
  • 面板阴影 token 化：TokenValueEditor 用 shadow-md（Tailwind 默认），其它都用自定义 shadow-pop，应抽 CSS variable --shadow-popover 统一。
  • Footer 布局规范：footer 高度 / padding 不齐（h-9 / py-2 / py-3 混用）。建议统一 border-t px-1 h-9 或 border-t px-3 py-2 二选一。

P2 · 抽象更高层组件 低优先级

  • 抽 SelectPanel 通用骨架：所有筛选面板都是「搜索框 + 列表区 + Footer」三段式，可抽出 <SelectPanel header={Search} body={...} footer={...} /> 复用。
  • 统一交互模型 props：在SelectPanel层提供 commitMode: "instant" | "confirm" 切换"即时生效 / 确认生效"，避免重复实现 ScopeFilter（即时） vs TableHeaderFilter（确认）。
  • 触发器变体下沉：把"按钮触发器 / Filter icon 触发器 / 徽章+铅笔触发器"做成 FilterTrigger 三个 variant，业务方按场景选择。
  • 收敛 SearchableSelect 与 Select：Select 加 searchable prop，长列表自动启用搜索，避免维护两套触发器。
  • 建立 Storybook/preview 页面：在 ComponentPreview.tsx 中集中陈列所有筛选面板的样式 demo，作为视觉对齐 ground truth。

规范沉淀

  • 在 SKILL.md / SKILL-GLOBAL-COMPONENTS.md 增设"下拉/筛选面板规范"小节，约束：① 容器圆角 4px、② 选项行 h-8 px-3 rounded-[6px]、③ 阴影使用统一 token、④ 选中态颜色使用 --bg-brand-selected + text-blue-500、⑤ Footer 三段式。
  • 在 ESLint 自定义规则或 stylelint 中加规则：禁止裸 bg-blue-50 / bg-[#EFF4FF]，强制走 token。
