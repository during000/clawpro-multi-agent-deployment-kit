# 企业技能库功能介绍

企业技能库（Agent 工具库）是 OpenClaw Enterprise 管理端的核心模块，统一管理 AI 智能体所需的技能（Skill）、插件（Plugin）和 MCP 服务。管理员可通过该模块完成工具资产的全生命周期管理，并将其按需下发到运行中的智能体实例。

---

## 一、管理：组织管理

技能库与平台「用户管理 → 组织」模块打通，支持按组织维度控制技能的可见范围：

- **应用范围**：每个技能/插件可设置为「全部用户」或「按组织」，按组织时可关联一个或多个用户组织
- **组织联动**：组织数据直接复用用户管理模块的组织列表，无需重复维护
- **分类管理**：企业技能库内置 10 个分类标签（通用办公、研发工具、系统运维等），支持管理员新增和编辑分类

## 二、操作

### 2.1 上传 / 新增

- **技能（Skill）**：支持 ZIP 包上传和文件夹上传两种方式。系统自动解析 ZIP 中的 `SKILL.md` 文件，提取 name、description 等元信息自动填充表单。上传后需填写唯一标识（slug）、版本号、分类、应用范围等信息
- **MCP 服务**：通过两步表单创建——第一步填写服务 ID、连接方式（SSE / Streamable HTTP / STDIO）和 JSON 格式的服务配置；第二步填写使用说明和工具说明（Markdown 格式）。编辑器固化外层 JSON 结构，用户仅需编辑核心配置

### 2.2 列表 / 查看

- **列表视图**：支持列表和卡片两种视图模式切换，支持按名称、描述等关键字搜索
- **详情页**：三栏布局（版本列表 → 文件列表 → 内容展示），支持多版本切换查看，Markdown 文件提供「预览 / 源码」两种模式

### 2.3 更新

- **版本管理**：更新时可替换文件、修改名称/描述/分类/应用范围，版本号需高于当前版本（semver 格式校验）
- **更新说明**：支持「一键生成」changeLog，自动检测哪些字段发生了变更
- **安全检测**：上传和更新时可选提交安全检测，由科恩实验室、云鼎实验室双引擎进行安全分析（覆盖供应链风险、命令执行、网络外传、Prompt 注入等 8 个维度）

### 2.4 下载

- 详情页支持将技能文件按版本打包为 ZIP 下载
- 提供样例 Skill ZIP 下载（`skill-creator.zip`），方便用户参考标准格式

### 2.5 删除

- 删除操作使用二次确认弹窗（AlertDialog 危险操作样式）
- 如果技能被初始技能包引用，删除时会列出引用的包名称并给出警告

### 2.6 下发（TAT + curl 包模式）

- **批量下发**：选择目标智能体实例 → 确认下发 → 系统将技能/MCP 配置推送到实例上的 `~/.openclaw/` 目录
- **筛选限制**：仅展示满足条件的实例（智能体类型为 OpenClaw、状态为运行中、下发状态为未下发或失败）
- **下发流程**：提供一个curl包流程，tat执行
- **下发记录**：每次下发生成独立记录，包含时间、进度、各实例状态（成功/失败/进行中），支持查看详情和按状态筛选
- **实时反馈**：下发过程中显示进度条动画，完成后 toast 提示结果

## 三、附属功能

以下功能本质上是列表 + 下载能力的复合拼凑，不涉及独立的复杂逻辑：

### 3.1 初始技能包

- 管理员可创建多个「初始技能包」，从公共技能库或企业技能库中选取技能组合
- 支持设置应用范围（全部用户 / 按组织），支持「生效 / 草稿」状态管理
- 技能包内的技能支持版本刷新（检测公共库/企业库是否有更新版本）

### 3.2 公共技能库

- 展示平台预置的公共技能列表，支持按分类筛选和分页浏览
- 支持「收藏」功能和「加入初始技能包」操作
- 技能详情页展示文件树、版本历史和 Markdown 预览

### 3.3 角色预设

- 预设角色列表展示，每个角色包含名称、描述、适用场景等信息
- 支持查看和下载角色配置

## 四、技术要点

- **数据持久化**：使用 localStorage 缓存列表数据和下发记录，带版本管理（版本号变更时自动清除旧缓存）
- **组件复用**：批量下发弹窗（BatchDistributeDialog）、删除确认弹窗（DeleteSkillDialog）、下发缓存模块（distributionCache）在技能/插件/MCP 三个 Tab 间复用，通过配置参数差异化
- **前端 Mock**：当前所有数据使用 useState + mock 模式，不调后端 API
