# ClawPro 管控端本地 Agent 模型配置下发需求单

## 需求概览

| 端 | 分类 | 模块 | 优先级 | 预期时间 |
|---|---|---|---|---|
| 管控端 | 功能新增 | 模型配置 | P0 | 待排期 |

## 一、管控端

### 需求点一：模型下发入口

#### 1. 入口位置

在“模型配置”页面的模型列表操作区提供“下发”入口。

管理员点击“下发”后，打开当前模型的“下发模型配置”弹窗，不新增独立页面或子 Tab。

本地 Agent 与云端 Agent 复用同一套企业模型库。管理员继续通过现有“添加模型”入口创建平台托管模型，不新增“本地模型”类型或独立创建入口；模型创建成功并满足下发条件后，可直接从同一模型列表发起下发。

#### 2. 展示规则

- 已开启“用户可见”的模型展示可操作的“下发”入口。
- 未开启“用户可见”的模型不允许下发，入口置为不可操作，并提示“请先开启用户可见”。
- 通过“添加模型”创建且可由 ClawPro Proxy 调用的平台托管模型支持下发，包括 Proxy 已兼容接口类型的管理员自定义模型。
- 用户在单个实例中自行配置、由 Agent 直连上游的自定义模型不支持本期下发能力。
- 模型列表不增加“本地 Agent”数量、状态或下发结果列，目标 Agent 与状态统一在下发弹窗中查看。
- 仅企业管理员可以使用下发能力；无权限用户不展示入口或由平台统一拦截。

#### 3. 验收标准

- 管理员可以在模型列表的操作区找到“下发”入口。
- 点击入口后，弹窗正确展示当前模型名称和模型标识。
- 管理员通过现有“添加模型”创建模型后，无需重复创建本地版本即可发起下发。
- 未开启“用户可见”的模型不能发起下发。
- 模型列表不因本功能增加本地 Agent 相关列。

### 需求点二：目标本地 Agent 选择

#### 1. Agent 信息

“下发模型配置”弹窗展示以下信息：

- 本地 Agent 名称及归属用户。
- 本地客户端类型及版本。
- 连接状态：在线、离线。
- 当前模型。
- 当前模型对应的下发状态。

#### 2. 搜索与筛选

- 支持按本地 Agent 名称或归属用户搜索。
- 支持按本地客户端类型筛选，包括 CodeBuddy、WorkBuddy、Claude、Codex。
- 支持按下发状态筛选，包括未下发、下发成功、下发失败；“下发中”作为过程状态，不提供独立筛选项。
- 搜索、本地客户端和下发状态筛选条件组合生效。
- 页面实时展示当前已选择的 Agent 数量。
- 没有符合条件的 Agent 时展示空状态，不保留空白表格内容。

#### 3. 选择规则

- 模型应用范围包含该 Agent 的归属用户组时，Agent 可以选择。
- 模型应用范围不包含该 Agent 的归属用户组时，Agent 不可选择，并展示“不在应用范围”。
- 打开下发弹窗时默认不选中任何 Agent，管理员需手动勾选或使用全选。
- 在线与离线 Agent 均可选择，离线状态不阻止管理员创建下发任务。
- 全选仅作用于当前搜索和筛选结果中可下发的 Agent，不包含应用范围外的 Agent。
- 当前已成功配置该模型的 Agent 可以手动选择并重新下发。
- 未选择任何 Agent 时，“确认下发”不可操作。

#### 4. 验收标准

- 管理员可以通过搜索和客户端筛选快速定位本地 Agent。
- 管理员可以通过下发状态筛选定位未下发、成功或失败的 Agent。
- 组合筛选结果与当前搜索、客户端和下发状态条件一致。
- 弹窗首次打开时已选数量为 0，不会自动创建批量选择结果。
- 在线和离线 Agent 均可以加入下发任务。
- 应用范围外的 Agent 有明确原因且不可选择。
- 全选不会选中应用范围外的 Agent。
- 已选数量与实际勾选结果一致。

### 需求点三：ClawPro Proxy 与凭据

#### 1. 页面说明

弹窗不展示 Proxy 接口路径、Token 格式等研发参数，仅保留管理员需要了解的安全边界：

> 本地 Agent 将通过 ClawPro Proxy 调用该模型。上游 API Key 保留在 ClawPro 服务端，不会下发到本地；平台为每个 Agent 使用独立访问凭据。

#### 2. 下发内容

本地 Agent 接收并应用以下模型访问配置：

- ClawPro Proxy 地址。
- 模型标识及主模型配置。
- Agent 专属 Proxy Token。

平台不得将 Claude Platform、OpenAI 或其他上游模型服务的 API Key 下发到本地 Agent。

#### 3. 安全规则

- 每个本地 Agent 使用独立的 Proxy Token，不允许多个 Agent 共用同一长期 Token。
- Token 应支持签发、轮换、吊销和失效处理。
- Proxy 根据 Agent 身份校验企业、用户、模型权限、应用范围和配额。
- 管控端列表、弹窗和下发记录均不展示完整 Proxy Token 或上游 API Key。
- 本需求中的 Claude 接入指 Claude Platform API Key，不包括 Claude Pro、Max 等订阅账号、Cookie 或网页登录凭据。

#### 4. 验收标准

- 页面能够清楚说明 Proxy 中转方式和凭据安全边界。
- 弹窗不展示 Proxy 接口路径、Token 格式或其他不可操作的研发参数。
- 本地 Agent 无需获取上游 API Key 即可通过 ClawPro Proxy 调用模型。
- 不同 Agent 的 Proxy Token 可以独立吊销，且不会影响其他 Agent。
- Token 无效、权限不足或模型不可用时，Proxy 拒绝请求并返回可识别的错误结果。

### 需求点四：创建下发任务

#### 1. 确认下发

管理员选择一个或多个本地 Agent 后，点击“确认下发”创建下发任务。

按钮展示本次目标数量，例如：

`确认下发（3）`

任务创建期间按钮展示“下发中…”，不可重复点击；任务成功创建后关闭弹窗并展示轻提示：

> 下发任务已创建。已为 3 个本地 Agent 创建下发任务；离线 Agent 将在恢复连接后继续下发。

#### 2. 在线 Agent 处理

- 在线 Agent 在接收到任务后写入模型访问配置并返回处理结果。
- Agent 成功应用配置后，状态更新为“下发成功”，当前模型更新为本次下发模型。
- 前端以平台返回的任务结果为准，不根据本地计时直接判定成功。

#### 3. 离线 Agent 处理

- 离线 Agent 可以正常创建下发任务。
- Agent 恢复连接前，任务保持“下发中”。
- Agent 恢复连接后，平台自动继续投递，不要求管理员重新创建任务。
- 最终状态根据 Agent 回执更新为“下发成功”或“下发失败”。

#### 4. 重复任务规则

- 同一 Agent、同一模型已存在进行中的任务时，不重复创建相同任务。
- 管理员对失败任务重新下发时，创建新的任务记录，历史结果继续保留。
- 管理员对已成功配置的 Agent 重新下发时，按新的下发任务处理，用于刷新配置或 Token。

#### 5. 验收标准

- 未选择 Agent 时不能提交任务。
- 点击“确认下发”后不能重复提交同一批任务。
- 在线 Agent 可以完成配置应用并返回结果。
- 离线 Agent 不会被直接判定为失败，恢复连接后能够继续处理。
- 重新下发不会覆盖或删除历史记录。

### 需求点五：下发状态与结果反馈

#### 1. 状态口径

下发状态统一使用以下四种口径：

- 未下发：尚未向该 Agent 创建当前模型的下发任务。
- 下发中：任务已创建，当前正在等待投递、等待 Agent 回执或处理中。
- 下发成功：Agent 已成功应用当前模型配置。
- 下发失败：任务未完成，管理员可以查看失败原因并重新下发。

不使用“待同步”“已同步”“部分成功”“模拟下发”等其他状态文案。

#### 2. 成功反馈

- 当前模型更新为本次下发模型。
- 下发状态更新为“下发成功”。
- 页面使用轻提示反馈任务结果，不展示额外成功弹窗。

#### 3. 失败反馈

- 当前模型保留最近一次成功应用的模型，不根据失败任务提前更新。
- 下发状态更新为“下发失败”。
- 页面展示管理员可理解的失败原因和重试建议。
- 不直接展示完整 Token、内部目录、命令、堆栈或原始系统错误。

#### 4. 状态恢复

- 页面刷新后通过平台接口恢复真实下发状态。
- 任务状态变化后，Agent 列表和下发记录保持一致。
- 平台应记录任务创建、投递、Agent 回执和最终结果时间。

#### 5. 验收标准

- 页面仅使用“未下发、下发中、下发成功、下发失败”四种状态。
- 下发成功后当前模型与平台返回结果一致。
- 下发失败不会错误覆盖 Agent 当前有效模型。
- 页面刷新后不会丢失进行中的任务状态。
- 失败信息不包含敏感凭据或内部实现细节。

### 需求点六：下发记录

#### 1. 查看入口

在“下发模型配置”弹窗中提供“下发记录”入口。

管理员点击后，在当前弹窗内切换到“下发记录”，并可以通过“返回下发配置”继续选择 Agent，不新增独立页面。

#### 2. 展示内容

下发记录仅展示当前模型对应的历史结果，按 Agent 粒度展示：

- 下发时间。
- 本地 Agent。
- 结果。

记录列表不增加“说明”列；失败原因通过状态详情或后续失败信息能力查看。

#### 3. 结果口径

- 进行中的任务展示“下发中”。
- 成功任务展示“下发成功”。
- 失败任务展示“下发失败”。
- 离线 Agent 恢复连接前保持“下发中”，收到回执后更新为最终结果。
- 没有记录时展示“暂无下发记录，请先返回选择 Agent 进行下发”。

#### 4. 验收标准

- 管理员可以从下发弹窗查看当前模型的历史下发记录。
- 记录不会混入其他模型的下发结果。
- 每次重新下发都会保留独立记录。
- 列表仅展示下发时间、本地 Agent 和结果，不展示无业务价值的说明列。
- 下发配置与下发记录之间可以正常往返切换。

### 需求点七：后台下发链路

#### 1. 云端能力复用

ClawPro 云端 Agent 现有模型配置采用“控制面配置下发 + 数据面 Proxy 转发”的两段式链路：

1. 管理员在 ClawPro 配置平台托管模型及上游 API Key。
2. ClawPro 服务端保存模型配置，并将模型绑定到云端实例。
3. Hatchery 通过腾讯云 TAT 执行 `set_model.sh`，向 CVM 写入 Proxy 地址、模型标识和实例专属 `proxy_token`。
4. 云端 Agent 运行时使用 `proxy_token` 调用 ClawPro LLM Proxy。
5. Proxy 完成身份、模型权限和配额校验后，使用服务端保存的 API Key 调用上游模型。

本地 Agent 复用模型库、模型绑定、凭据托管、LLM Proxy、配额和审计能力，但不能依赖腾讯云 TAT。

#### 2. 本地 Agent 下发通道

后台需为本地 Agent 提供可用的配置接收通道，可以采用长轮询、WebSocket 或 Agent 主动拉取任务等实现，具体协议由研发设计确定。

下发链路至少包括：

1. 创建本地 Agent 模型绑定和下发任务。
2. 识别本地 Agent 身份及所属企业、用户和用户组。
3. 签发或获取该 Agent 的专属 Proxy Token。
4. 向 Agent 投递 Proxy 地址、模型标识和 Proxy Token。
5. Agent 写入配置并返回成功或失败回执。
6. 平台更新任务、当前模型和下发记录。

#### 3. 后台能力

- 建立本地 Agent 身份与企业、用户、用户组的映射关系。
- 提供 Agent 专属 Proxy Token 的签发、轮换、吊销和过期机制。
- 支持下发任务创建、查询、去重、重试和取消。
- 支持离线任务保留及 Agent 恢复连接后的自动投递。
- 支持 Agent 回执、失败原因分类和最终状态落库。
- 支持模型绑定、应用范围、权限和配额校验。
- 记录管理员、模型、目标 Agent、时间和结果等审计信息。

#### 4. 异常处理

- 模型在任务处理前被停用、删除或移出应用范围时，平台终止未投递任务，并将结果更新为“下发失败”。
- Proxy Token 无效或已吊销时，平台不得继续向 Agent 提供模型服务，并返回认证失败结果。
- Agent 回执超时但仍可能恢复时，任务保持“下发中”；超过后台规定的最终有效期后更新为“下发失败”。
- 非企业管理员创建任务时，平台拒绝请求且不产生下发记录。

#### 5. 验收标准

- 本地 Agent 可以在不依赖腾讯云 TAT 的情况下接收模型配置。
- 上游 API Key 全程保留在 ClawPro 服务端。
- Agent 可以通过专属 Proxy Token 调用已获授权的模型，不能调用未绑定或不在应用范围内的模型。
- 离线、重试、失败和 Token 失效均有可查询的真实任务状态。
- 管控端展示结果与后台任务、Agent 回执和审计记录一致。

## 二、范围与边界

### 1. 本期包含

- 管控端模型列表中的“下发”入口。
- 本地 Agent 搜索、筛选、选择与应用范围判断。
- 在线、离线 Agent 的任务创建和状态展示。
- 当前模型的下发记录查询。
- 本地 Agent 身份、模型绑定、专属 Token、配置投递、回执、重试和审计后台能力。
- ClawPro Proxy 对本地 Agent 的身份、模型权限和配额校验。

### 2. 本期不包含

- Claude Pro、Max 等订阅账号、Cookie 或网页登录凭据下发。
- 将平台托管模型的上游 API Key 写入本地 Agent。
- 用户自定义模型统一迁移到 ClawPro Proxy 的策略。
- 本地 Agent 运行环境安装、升级或跨 Agent 类型迁移。

### 3. 待研发评审

- 本地 Agent 配置接收通道采用长轮询、WebSocket 还是 Agent 主动拉取。
- 下发任务和 Agent 回执接口定义、超时时间及最终有效期。
- Proxy Token 的有效期、轮换触发条件和吊销方式。
- 标准失败原因分类及面向管理员的提示文案。
- 用户自定义模型是否在后续版本统一通过 ClawPro Proxy 中转。
