# 技能实例卸载（从已下发实例中移除）

## 一、功能概述

在企业技能库 → 技能详情 → **下发和卸载记录** Tab 中，新增「批量卸载实例」能力。管理员可选择已下发的 Agent 实例，批量移除其上已安装的技能。

> **与"删除技能"的区别**：现有的「删除」按钮是从企业技能库中删除整个 Skill 记录；本需求是从已下发的 Agent 实例上**卸载/移除**该技能，技能本身仍保留在库中。

---

## 二、入口与 UI 变更

### 2.1 Tab 名称变更

| 变更前 | 变更后 |
|--------|--------|
| 下发记录 | 下发和卸载记录 |

### 2.2 记录筛选

Tab 顶部新增筛选按钮组（SegmentedControl 风格）：

| 筛选项 | 说明 |
|--------|------|
| 全部 | 显示所有下发记录 + 卸载记录（默认） |
| 下发记录 | 仅显示下发类型的记录 |
| 卸载记录 | 仅显示卸载类型的记录 |

### 2.3 新增「批量卸载」按钮

在 Tab 顶部，与现有「批量下发」按钮并列，新增「批量卸载」按钮。

## 三、批量卸载流程

### 3.1 打开卸载弹窗

点击「批量卸载」→ 打开实例选择弹窗。

**弹窗内容：**
- 标题：批量卸载实例（无图标，纯文本标题，样式参考下发弹窗）
- 提示文案：`通过下发按钮安装的技能可支持移出（包括用户下发和管理端下发）。卸载成功后，该技能在对应实例上恢复为"未下发"状态。`
- 布局：采用卡片式列表（flex 布局），样式参考下发弹窗 BatchDistributeDialog
- 组织筛选：下拉框，可按实例对应用户的组织过滤实例列表
- 下拉框，可以按照【状态过滤】【卸载失败】【未卸载】，默认全选
- 实例列表（卡片式列表）：
  - 左侧：复选框
  - 中间：实例名称 + 实例 ID（第1行）、创建人 + 组织（第2行）
  - 右侧：卸载状态（上）+ 版本号（下）

- **数据来源**：仅展示当前技能已成功下发的实例（有下发成功过一次就算），未下发 / 下发失败的不展示
- 底部按钮：「确认卸载」（主按钮，红色）+「取消」

### 3.2 执行卸载

点击「确认卸载」后：
1. 弹窗关闭
2. 在「下发和卸载记录」列表中**顶部插入一条新的卸载记录**
3. 状态为「卸载中 xx%」，带进度条（与下发中的进度条样式一致）


### 3.3 卸载中的互斥限制

当存在**卸载中**的任务时，以下操作置灰禁用：
- 批量下发按钮
- 批量卸载按钮
- 更新技能按钮

> 与现有「下发中」的互斥逻辑一致：改为【卸载中】`hasInProgress` 判断条件扩展为包含 distributing 和 deleting 两种状态。

## 四、卸载记录展示

### 4.1 记录卡片样式

卸载记录在列表中使用**浅红色底色**（`bg-red-50 border-red-200`），与下发记录（白色底色）区分。

| 状态 | 显示 | 样式 |
|------|------|------|
| 卸载中 | `卸载中 xx%` + 进度条 | |
| 卸载完成 | `卸载完成，1个成功，0个失败` | 

### 4.2 记录卡片内容

```
#序号 ·  2026-01-01 12:00:00
                              [卸载完成，3/5 成功]  [查看详情]
```

与下发记录格式一致

### 4.3 查看详情弹窗

点击「查看详情」打开弹窗，复用现有下发详情弹窗的布局：

**弹窗内容：**
- 标题：卸载详情
- 筛选按钮组：全部 / 成功 / 失败 / 卸载中
- 搜索框：按实例名称搜索
- 实例列表（表格）：

| 列名 | 说明 |
|------|------|
| 实例名称 | Agent 实例名称 |
| 实例 ID | Agent 实例 ID |
| 卸载状态 | 成功（绿色）/ 失败（红色） |
| 失败原因 | 仅失败时显示，如"实例离线"、"权限不足"等 |

### 列表页
也是类似，和下发状态那类似的位置和交互。
改为【卸载中】百分之几，卸载完成，xxxx

## 六、状态流转

```
已下发实例 → 选择卸载 → 卸载中(deleting) → 卸载完成
                                              ├── 成功 → 实例恢复为"未下发"
                                              └── 失败 → 实例保持原状态，记录失败原因
```

---

## 七、Mock 数据逻辑（前端演示）

1. **卸载进度**：点击确认后 10s 内模拟进度从 0→100%（与下发进度逻辑一致）
2. **卸载结果**：随机生成每个实例的卸载结果（90% 成功，10% 失败）
3. **失败原因**：随机从预设列表中选取（"实例离线"、"权限不足"、"技能被占用"等）
