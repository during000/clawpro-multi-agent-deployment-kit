# 用户端工具库（MCP 管理）— 需求单

> 模块：租户端（Tenant）| 位置：用户端 OpenClaw 详情页「基础配置」下方新增 Tab
> 基线：复用管控端 MCP 数据，用户可查看、选配、连接企业 MCP

---

## 一、功能概述

在用户端 OpenClaw 详情页的「基础配置」下方新增**「工具库」** Tab，用户可以查看企业已配置的 MCP 列表及联通状态，选配需要的 MCP，填写密钥等参数，并管理已添加的 MCP。

页面布局与基础配置一致：左侧导航 + 右侧三列内容区。MCP 配置列表放在第一列，后两列暂留空。


# 排期

**一期（P0）**

- 管理端改造：`<xxx>` 标注用户自填参数 + 实例详情展示提示

## 二、管理端改造

### 新增 MCP 时标注用户自填参数

在管理端新增 MCP 时，需要用户自行填写的参数用 `<xxx>` 格式框住。例如某 MCP 需要用户提供 `api_key` 和 `base_url`，则配置中写为 `<api_key>`、`<base_url>`。

第一步顶部增加一个提示，用户可在租户端自选配此 MCP。如有需要用户自行填写的字段，请在配置中使用 <字段名> 格式标记。

在 MCP 详情页「实例内容」区域，代码库下方新增一行提示：

```
需用户填写参数：【api_key】【base_url】
```


用户端读取到这些 `<xxx>` 标记的参数后，会引导用户填写。

## 三、用户端页面

### 3.1 MCP 列表

**顶部操作栏**

- 标题：「MCP 配置」
- 右侧按钮：**添加 MCP**（按钮即可） + **刷新技能列表**（按钮，hover 提示「刷新技能列表」）
- 支持搜索（默认按上传顺序排序）
- 一行提示文字：状态验证仅支持公网访问的 MCP，本地命令和内网访问需登录实例自行校验。




**列表项展示**

每条 MCP 记录展示以下信息：

| 元素 | 说明 |
|------|------|
| 名称 | MCP 名称 |
| 状态 | 连接成功 / 连接失败（带颜色指示） |
| 描述 | 2行截断 |
| 工具列表 | 仅连接成功时展示。默认显示前 2 行，可点击展开全部，每个工具用标签样式展示 |
| 报错信息 | 仅连接失败时展示，红色字体 |
| 操作 | **刷新技能连接状态**（图标按钮，hover 1s 后提示「刷新技能连接状态」，仅刷新当前项）+ **查看源码**（图标按钮）+ **删除**（图标按钮）+【开启或关闭】按钮 |

### 3.2 添加 MCP

点击「添加 MCP」按钮，弹出对话框：

- 上方：搜索框，支持按名称/描述搜索，展示匹配的 MCP 名称和描述
- 列表：企业已配置的 MCP，有个「+」按钮

**无需填写参数时**：选中一个 MCP 后，弹出确认弹窗：
```
确认添加 xxx MCP 配置？
【取消】  【确认但不重启】  【确认并重启】
```

**需填写参数时**：弹出参数填写弹窗，填完后底部按钮为：
```
【取消】  【确认但不重启】  【确认并重启】
```
取消后返回模板列表。

### 3.3 查看源码

点击「查看源码」图标，弹出对话框展示该 MCP 的 JSON 配置：

- 固定展示最前面的 `server-name` 字段（不可编辑）
- 其余配置内容可自由编辑
- 顶部提供**格式化**按钮（整理 JSON 缩进）
- 保存时做 JSON 格式校验，格式错误时提示
- 底部按钮一次性选择（不做二次弹窗）：

```
【取消】  【保存但不重启】  【保存并重启实例】
```

### 3.4 删除 MCP

点击「删除」图标，弹出确认对话框（一次性选择，不做二次弹窗）：

```
确认删除 xxx MCP，删除后将不可使用。
【取消】  【删除但不重启】  【删除并重启实例】
```

### 开启/关闭

默认是开启的，如果关闭，注入      "disabled": true
修改后也是做提示
```
是否重启以生效？
【暂不重启】  【重启】【取消修改】
```
