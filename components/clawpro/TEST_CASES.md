# OpenClaw 企业版管控端测试用例文档

## 文档概述

本文档涵盖三个管控端页面的测试用例：
- **Tokens 监控（按会话）**
- **运维观测**
- **会话管理**

主要测试内容包括：OpenClaw 名称筛选器、CLS 日志服务启用/关闭、页面数据展示等功能。

---

## 一、Tokens 监控（按会话）

### 页面路径
`/admin/tokens-monitor` → 点击「按会话」标签页

### 页面元素
- **蓝色说明文案**：「查看所选时间范围内的模型 Token 使用情况...」
- **OpenClaw 名称筛选器**：Combobox 组件，位于说明文案下方左侧
- **关闭 CLS 服务按钮**：位于右上角
- **会话数据表格**：显示会话 ID、渠道、模型、Token 使用等信息

### 测试用例 1.2：开启 CLS 日志服务

| 项目 | 内容 |
|------|------|
| **用例编号** | TC-TM-002 |
| **用例标题** | 点击「开启 CLS 日志服务」按钮 |
| **前置条件** | 1. 用户已登录管控后台<br>2. CLS 日志服务未启用<br>3. 页面显示「开启 CLS 日志服务」按钮 |
