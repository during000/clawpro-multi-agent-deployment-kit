# ClawPro CodeBuddy 开发入口

@.codebuddy/rules/clawpro-collaboration-workflow.md

用户只需描述需求。每个独立新需求先自动同步工蜂全部 `feature/*` 到 Git 内部实时 TSV，再结合仓库内人工职责索引匹配分支；首次进入仓库/分支或职责发生变化时输出连续三行分支确认并停止，用户确认前禁止写代码。同一对话、仓库和分支内的补充修改、验证、预览、提交与 MR 复用已有确认；首次记录未提交修改基线，本次开发产生的修改不重复告警，只有未知新增修改、切换分支或覆盖风险才停止。确认后只操作该仓库和分支，保护公共基建，完成检查与 UI 直达预览。只有用户明确要求时才提交、推送；有可用的工蜂 API/CLI 时创建 MR，否则明确返回“MR 未创建”的预填链接。
