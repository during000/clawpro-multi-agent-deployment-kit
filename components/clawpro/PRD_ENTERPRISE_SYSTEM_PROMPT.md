# 企业系统提示词 PRD

## 背景

TeamAI-CLI 项目中，每个项目仓库根目录有一份 `CLAUDE.md` 作为 Agent 的系统提示词文档——Agent 每次会话自动加载，承载团队身份、工作准则、质量底线，并指引 Agent 去规范库/知识库获取细节。

本需求将该能力产品化到 ClawPro 管控端：管理员可统一管理各项目的系统提示词文档，并通过平台下发到目标工具（Claude Code / CodeBuddy）。

---

## 定位

「企业系统提示词」是 Agent 工具库的第 5 个企业资产库 Tab（前 4 个：技能库、MCP 库、插件库、规范库）。

**关键约束**：

- 每份设定绑定一个「项目」，同一项目通常只维护一份设定
- 下发放到各工具时落为各自文件（`CLAUDE.md` / `CODEBUDDY.md`），仅为落盘细节
- 提示词文档定位是「全局、精炼」的基础上下文，不写编码细则或操作步骤（细则归规范库，步骤归技能库）

---

## 数据模型

### TeamSetting

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| name | string | 提示词名称（如"ClawPro · 系统提示词"） |
| description | string | 一句话描述，列表展示用 |
| projectId | string | **关联项目 ID（关键信息）** |
| scope | `'public' \| 'private'` | 适用范围 |
| groupIds | string[] | scope=private 时关联的组织 ID |
| version | string | 版本号，保存时自动 `+0.1` |
| status | `'draft' \| 'distributed'` | 草稿 / 已下发 |
| updatedAt | Date | 最后更新时间 |
| content | string | 完整 Markdown 文档（含头部元信息） |

### 文档内容结构

```yaml
---
project: ClawPro
version: 2.1
updated_at: 2026-06-20
---

# 系统提示词（Team Context）

## 我们是谁
## 核心价值观与工作准则
## 协作与沟通风格
## 全局质量底线
## 引用入口
```

### 下发目标（当前仅支持 2 个）

| 工具 | 落盘文件 | 状态 |
|------|---------|------|
| Claude Code | `CLAUDE.md` | ✅ 支持 |
| CodeBuddy | `CODEBUDDY.md` | ✅ 支持 |
| Cursor / Cline / Windsurf | — | 🚧 暂不支持（置灰） |

## 页面结构

### 列表页

路径：`/admin/agent-tool-library?tab=settings`

| 区域 | 内容 |
|------|------|
| 顶部 | 4 个对比卡片（技能库 / 规范库 / MCP·插件库 / 设定库），右侧「下发说明」HoverCard |
| 工具栏 | 搜索框 + 卡片/列表视图切换 + 新建设定按钮 |
| 列表 | 名称/描述、关联项目、状态、适用范围、版本、更新时间、操作 |

**操作列**：
- 下发 → 弹出目标工具选择弹窗
- 编辑 → 打开编辑弹窗
- 更多 → 删除（二次确认）

**空态**：提示 + 新建设定 CTA

### 编辑弹窗

| 区域 | 说明 |
|------|------|
| 提示词名称 | 必填，文本输入 |
| 关联项目 | 必填，下拉搜索选择，有项目唯一性提示 |
| 一句话描述 | 选填 |
| 版本号 | 只读，自动升级（新建 1.0，编辑 +0.1） |
| 设定正文 | Markdown 编辑器 + 预览（单栏切换），支持填入标准模板 |
| 规范校验 | 实时检测：篇幅过长 warning / 疑似规则细则 info / 疑似操作步骤 info |

**项目唯一性**：选中项目中已存在另一份设定时，黄色提示"该项目已绑定设定「xxx」，建议改为编辑原设定"（不阻断保存）。

### 下发弹窗

- 列表展示所有目标工具，含工具名 + 落盘文件名
- Claude Code、CodeBuddy 可勾选（默认全选）
- 其余工具置灰 + "暂不支持"标签 + 底部说明"其余工具陆续接入中"
- 确认后 mock 下发，状态从草稿变为已下发

---

## 规范校验规则

| 检测项 | 级别 | 触发条件 |
|------|------|------|
| 篇幅过长 | ⚠ warning | 正文 > 1500 字 |
| 疑似编码规则细则 | ℹ info | 含缩进/命名/lint/禁用语法等关键词 |
| 疑似任务操作步骤 | ℹ info | 含步骤编号、操作指令等 |

## 与 TeamAI-CLI 的对应关系

TeamAI-CLI 中用户在项目仓库手动维护 `CLAUDE.md`，ClawPro 的产品化方案：

1. **集中管理**：管理员在平台统一编辑，而非各自在本地仓库维护
2. **项目绑定**：设定归属到具体项目，拉取时按项目匹配
3. **版本管控**：自动版本升级，可追溯变更
4. **多工具下发**：一份设定自动落成 Claude Code / CodeBuddy 等工具的对应文件
