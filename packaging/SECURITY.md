# 安全说明

- 本部署包用于测试和演示，不承诺生产级高可用、容灾和合规能力。
- 安装时会为每台服务器重新生成管理员密码、后台 Token 和 Cookie 密钥。
- 用户电脑必须使用 ClawPro 用户 API Token，不得把服务器后台管理员 Token 下发给用户。
- 用户 Token 应存放在权限为 `0600` 的本地文件中，不要写入命令历史、源码、工作流资产或日志。
- 必须通过 HTTPS/WSS 对外提供服务；不要把包内 HTTP 80 端口直接暴露到不可信网络。
- iWiki、CloudAgent、iMate 等外部能力需单独授权，部署包不会复制现有环境凭证。
- 对外发布前必须确认 ClawPro 前端构建产物与 Hatchery 二进制的内部代码分发权限。建议使用企业内部制品库、工蜂仓库或私有 GitHub 仓库。
